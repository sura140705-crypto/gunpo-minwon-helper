# 함정 목록 (조용히 실패하는 것들)

이 프로젝트에서 실제로 시간을 잡아먹었거나 **틀린 결과를 맞은 것처럼 보이게 만든** 것들.
새로 맡는 사람(또는 AI)이 같은 곳에 빠지지 않도록 증상 → 원인 → 대응으로 적는다.

## 개인정보 · DRM (이 PC 환경)

**① 만들어 둔 PDF를 나중에 열면 `no objects found`**
DRM 에이전트(Fasoo)가 새로 생성된 파일을 몇 분 뒤 암호화한다(헤더가 `DRMONE … Fasoo DRM` 으로 바뀐다).
파일이 깨진 게 아니라 암호화된 것.
→ **생성(print-to-pdf) → 래스터화 → 비교를 한 프로세스 안에서 끝낸다.** 기존 PDF 재사용 금지.
크롭 영역을 추가하고 싶으면 분석 스크립트를 고쳐 **전체를 다시 실행**한다. `tools/verify-print.py` 가 이 구조를 따른다.

**② 날짜를 하이픈으로 쓰면 문서가 암호화된다**
연·월·일을 하이픈으로 끊은 표기를 DLP가 주민등록번호 등 개인정보로 오인한다.
→ 문서·산출물의 날짜는 **`2026.08.04` 처럼 점**으로. 점 표기는 검사를 통과한다.
전화·주민등록번호 모양의 예시 문자열도 문서 본문에는 넣지 않는다(서식 인쇄물은 서식 규격이라 예외).

**③ `운영문서/보안성검토서.pdf` 는 추적하지 않는다**
외부 수령본이고 DRM으로 묶여 있어 커밋해도 다른 PC에서 열리지 않는다. `.gitignore` 처리됨.

## 도구 · 셸

**④ Bash 도구의 heredoc이 백슬래시를 한 단계 먹는다**
`"\\n"` 이 파이썬에 실제 개행으로 도착해, 소스에 리터럴 `\n` 을 넣는 치환이 **찾기 0건**으로 조용히 실패한다.
→ 소스에 백슬래시를 넣어야 하면 `chr(92)` 로 조립하거나 **Write/Edit 도구**를 쓴다.

**⑤ 파이썬이 한글·✓ 출력에서 `UnicodeEncodeError`**
콘솔이 cp949.
→ 스크립트 첫머리에 `sys.stdout.reconfigure(encoding="utf-8")`.
헤드리스 `--dump-dom` 결과와 한글을 비교할 때는 인라인 `python -c` 리터럴이 깨져 **오판**할 수 있으니 UTF-8 `.py` 파일로 읽어 비교한다.

**⑥ 크롬 헤드리스 file URL 형식**
`file:///C:/...` 만 동작한다. `file:///c/...`(Git Bash 경로)는 `ERR_FILE_NOT_FOUND`.
PyMuPDF `fitz.open` 과 `--print-to-pdf` 는 **절대경로**로 준다(작업 디렉터리 유지가 불안정).

**⑦ Bash 도구의 작업 디렉터리가 이전 명령의 `cd` 를 물고 있다**
앞 명령에서 `cd 운영문서` 를 했으면 다음 명령도 거기서 시작한다 → grep 결과가 0건으로 나와 "없다"고 오판.
→ 중요한 검색은 `cd /c/gunpo_minwon &&` 로 시작하거나 절대경로를 쓴다.

**⑧ `tools/build-form.js` 의 2번째 인자는 ROOT 기준 상대경로만 받는다**
절대경로를 주면 `C:\gunpo_minwon\C:\…` 로 붙어 ENOENT.

**⑨ base64 중간 파일이 쓰기 후 손상되는 일이 있었다**
→ 배경 렌더 + 주입은 **한 파이썬 스크립트 in-memory** 로 처리한다(중간 `.txt` 회피).

## 렌더 · 좌표

**⑩ 값이 라벨 줄이 아니라 인쇄된 단위 글리프 줄에 놓인다**
`㎡`·`원` 같은 단위가 라벨보다 7~10pt 아래인 칸이 많다(부동산 서식에서 20건 보정).
→ 처음부터 `get_text("rawdict")` 로 **단위 글리프 중심(mid)** 을 뽑아 y로 쓴다. 라벨 word의 `y0` 을 쓰면 어긋난다.

**⑪ 체크 표시는 ✔ 렌더로 판단한다**
✔ 글리프는 앵커에서 약간 우하로 보이므로, □ 좌상단 좌표로도 칸에 맞게 보인다.
반면 점(dot)은 정중심에 찍혀 좌상단으로 보인다 → **검증은 실제 표기 렌더로** 한다.

**⑫ 선택 표기 기호는 서식 머리말이 지시한다**
가족관계등록 신고서 5종 = 영표 `○`, `[ ]` 를 쓰는 부동산거래계약 신고서 = `✔`(8pt).
→ 새 서식은 **머리말의 표기 지시를 먼저 읽는다**. 엔진의 `FORM.checkMark`/`checkSize` 로 지정.

**⑬ 라벨이 칸을 다 먹는 칸이 있다**
「주민등록번호(법인ㆍ외국인등록번호)」 같은 긴 라벨은 여백이 7pt뿐 → 값을 라벨 **아래/윗줄**로 피신시킨다.

**⑭ 여권 `CO.checks.pages` 에 `"12면"` 키를 추가하면 안 된다**
긴급여권 12면 고정은 *`CO.checks.pages` 에 없는 키* 라서 renderForm 체크 루프가 건너뛰는 것에 의존한다.
키를 추가하면 체크가 찍히기 시작한다.

**⑮ 위임장 등을 `.cbox` 직속에 두면 가로로 깔린다**
`.cbox` 가 `display:flex`.
→ `.cbox > .cfields > .cline` 구조로 감싼다(동의서는 `clabel+cfields` 라 무관했다).

## 인쇄

**⑯ "인쇄물 크기·위치가 다르다"는 호소는 먼저 프린터 설정을 의심한다**
실제로 서식 배경을 시청 스캔본으로 교체하고 전체 좌표를 재정합한 뒤, **배율 100%·여백 없음으로 인쇄하니 원래 것이 맞았다**로 결론나 되돌렸다.
→ fit-to-page 대신 실제 크기 100%, 여백 0 부터 확인한다.

**⑰ `.form-col` 의 `max-height`/`overflow` 가 인쇄를 1뷰포트로 잘라먹는다**
→ print CSS에 `position:static; max-height:none; overflow:visible` 를 반드시 넣는다.

**⑱ 인쇄 페이지 아래 여백에 화면 배경색이 남는다**
→ 인쇄 CSS에 `html,body{background:#fff}`.

**⑲ 브라우저는 '인쇄함'과 '취소함'을 구분해 주지 않는다**
`afterprint` 는 취소 시에도 발생 → **취소해도 화면이 초기화**된다(설계상 한계).
인쇄 전 안내·매뉴얼·FAQ에 미리 알리는 것으로 처리했다. 고치려 들기 전에 이 한계를 먼저 인지할 것.

**⑳ 네이티브 `alert` 은 크기·글자색을 지정할 수 없다**
높이가 제한되고 넘치면 내부 스크롤 → 어르신이 못 읽는다.
→ 공용 스니펫의 `window.__printNotice(whyLine, onOk)` 화면 모달을 쓴다. 모달을 **제거한 뒤 60ms 후** `window.print()`(인쇄물 오염 방지).

**㉛ 인쇄물 기준선은 '오늘 날짜'에 의존한다 — 기준선 만든 다음 날부터 전부 실패**
서식에는 신청일·동의일이 **오늘 날짜로 찍힌다**(`APP_TODAY`). 그래서 코드를 한 줄도 안 고쳤는데
`verify-print.py` 가 19쪽 전부 회귀로 잡히고, diff 이미지를 열어 보면 **'일' 한 글자만** 빨갛다.
→ 도구가 렌더할 때 시계를 `FIXED_DATE`(2026.08.04)로 고정한다. 고정 스크립트(`CLOCK_FREEZE`)는
**`<head>` 첫머리**에 주입해야 한다 — 서식이 로드 시점에 `APP_TODAY=new Date()` 로 오늘을 붙잡으므로
`</body>` 뒤 주입은 이미 늦다.
⛔ **회귀가 날짜 자리에만 있으면 `--update` 를 하지 마라.** 기준선이 그날 날짜로 오염돼 다음부터 또 실패하고,
그 사이 진짜 좌표 회귀가 섞여 들어와도 못 잡는다.

**㉝ Electron 인쇄는 `pageSize` 를 안 주면 CSS 의 `@page{size:A4}` 를 무시하고 Letter 로 조판한다**
서식 CSS 가 `@page{size:A4 portrait;margin:0}` 이라고 선언해도 소용없다. 실측(Electron 33 / 크로미움 130):

| 조판 옵션 | 나온 용지 |
|---|---|
| `pageSize` 미지정 | **215.90 × 279.40mm (Letter)** |
| `pageSize:'A4'` | 210.23 × 297.35mm |
| `preferCSSPageSize:true` | 209.89 × 297.01mm ← 데스크톱 크롬 `--print-to-pdf` 와 동일 |

A4 조판을 Letter 에 맞추면 **가로 +2.9% · 세로 −5.9%** 로 두 축이 **반대로** 어긋난다. 증상이 고약하다 —
- 좌상단은 맞는데 **우측이 넘치고 아래는 남는다.** 균일 축소가 아니라서 **값이 칸을 벗어난다**
  (좌표·글자 크기가 `cqw` 단위라 **균일** 배율에는 끄떡없다. 비균일일 때만 깨진다).
- **프린터 여백을 0.0 으로 맞춰도 안 고쳐지고**, 프린터를 바꿔도 따라온다. 상류에서 이미 왜곡돼 나가므로.
- 그래서 "프린터 문제"로 보이고 좌표를 재정합하고 싶어진다 — ⑯ 과 같은 함정이다. **좌표를 건드리지 마라.**

→ 조판 옵션은 `kiosk-app/print-options.js` **한 곳**에 있다. 인쇄(`main.js`)와 검증이 같은 값을 쓴다.
→ `python tools/verify-print.py --electron` 이 용지를 검사한다. 옵션을 고쳤으면 반드시 돌려라.
⛔ 이 파일을 옮기거나 이름을 바꾸면 `package.json` 의 `build.files` 도 고쳐라 — 빠뜨리면 **포장된 실행본에서만** 죽는다.

**㉝-0 가장자리 손실은 프린터 몫이다 — 좌표로 흡수하지 마라**
용지를 A4 로 바로잡아도 **가로에 1mm 안팎이 남는다**(실측: 개발PC 1mm · 키오스크 2mm).
레이저 프린터의 인쇄 불가 영역·정합 공차라 소프트웨어로 못 없앤다. **기기마다 값이 다르므로**
한 대에 맞춰 좌표를 밀면 다른 기기에서 반대로 틀어진다.
→ 서식 8종 19쪽의 인쇄 내용은 전부 가장자리에서 **9.8mm 이상** 안쪽에 있다(실측). **1~2mm 손실은 무해하다.**
   예외는 여권 법정대리인 동의서(2쪽)의 회색 점선 절취선뿐 — 좌우 끝까지 닿지만 잘려도 무방하다.
→ 기기별 손실량은 `tools/calibration-sheet.html` 로 재서 **설치 검수 기록**으로 남긴다
   (합격 기준: 인쇄 불가 영역 9mm 이하 + 배율 100%).
⚠️ 여백을 재려고 기준선 PNG 를 분석할 때 **임계값 240 을 쓰지 마라.** 기준선은 16단계 양자화라
   **순백이 240** 이어서 종이 전체가 잉크로 잡힌다("여백 0mm"라는 헛값이 나온다).
   진한 잉크 ≤128, 옅은 회색 안내문(`#c4c4c4`→192)까지 ≤208 로 잡는다.

**㉞ 여권발급신청서는 드롭아웃 컬러 서식이다 — 흑백으로 뽑으면 스캔 판독이 실패한다**
기재칸 테두리가 **빨강(255,0,0)** 으로 인쇄돼 있고, 접수처는 스캔할 때 빨강을 걸러내 적힌 글자만 읽는다.
이것을 흑백 프린터로 뽑으면 빨강이 **밝기 76 의 검은 선**이 되어 드롭아웃이 안 되고, 테두리와 글자가 엉킨다.
원본 유채색 픽셀이 **17.2%** 이고(살구색 기재란 배경 6.2% · 빨강 0.6%), 서식 CSS 에도 원래
`(A4 규격 · 컬러 인쇄)` 라고 적혀 있다.
⛔ **위치를 의심하지 마라.** 우리 서식은 원본 별지서식과 **0.09mm** 안에서 일치한다(측정 완료).
   판독이 안 되면 색부터 본다. 삼성 ProXpress `M332x/382x/402x` 는 **모노 전용**이라 빨강을 못 낸다.
→ 정답은 컬러 프린터다. 그 전까지는 **겹쳐 찍기**(㉞-1)로 버틴다.

**㉞-1 겹쳐 찍기(미리 인쇄된 서식에 값만) — 프린터 공차가 그때부터 진짜 어긋남이 된다**
`kiosk.json` 의 `overlayPrintForms` 에 서식 키를 넣으면, 그 서식은 **값만** 인쇄된다
(`main.js` 가 `insertCSS` 로 주입 — **서식 HTML 은 건드리지 않는다**. 그래서 재빌드·동기화·기준선이 그대로다).
숨기는 것은 `.bg`(**`visibility:hidden`** — `display:none` 이면 `.stage` 높이가 사라져 좌표 기준이 무너진다) ·
`.cover` · `.guide` · `.ovhi`.

⛔ **키를 안 적으면 꺼지는 게 아니라 `['passport']` 로 켜진다**(2026.08.13~). 설정 파일이 없어지거나
   초기화돼도(하드보안관 복원·재설치) 여권이 흑백 서식째 나가지 않게 하려는 것이다.
   **끄려면 `"overlayPrintForms": []` 를 명시**해라 — 키를 지우면 기본값이 다시 켜진다.
   `--selfcheck` 의 「겹쳐 찍기」 줄에 `(설정)`/`(기본값)` 으로 출처가 찍힌다.
⚠️ 설정 파일을 **BOM 붙여 저장하면 `JSON.parse` 가 실패해 설정 전체가 무시된다**(프린터 지정까지).
   메모장은 `UTF-8`(BOM 아님)로, PowerShell 리다이렉트(`>`)는 쓰지 마라. `main.js` 가 BOM 을 떼긴 하지만
   그건 선두 BOM 하나뿐이다.

⚠️ **서식과 값을 함께 찍을 때는 프린터가 밀어도 둘이 같이 밀려 무해했다.** 겹쳐 찍기에서는 칸이 종이에
   고정돼 있고 값만 움직인다 — 기재칸 높이 **약 7mm** · 글자 **약 4mm** 라 위아래 여유가 **±1.5mm** 뿐인데
   프린터 정합 공차가 ±1~2mm 다. **기기별로 반드시 실물 확인**하고, 기울어짐(skew)이 있으면 못 쓴다.

⛔ **2쪽에는 안 걸린다 — 법정대리인 동의서·위임장은 배경 이미지가 없다.**
   여권 1쪽은 `.bg` 이미지 위에 값을 얹지만, 2쪽(`.consent-page`·`.proxy-page`)은 **HTML 로 직접 그린**
   서식이라 숨길 `.bg` 가 없다. 겹쳐 찍기를 켜도 2쪽은 **서식째 그대로** 나온다.
   실측(잉크 비율 · Electron 경로): 1쪽 10.0%→**0.71%** / 2쪽 4.18%→**4.18%**(변화 없음).
   → 트레이에 미리 인쇄된 신청서를 넣고 미성년자 신청을 받으면 **2번째 장이 그 위에 겹쳐 찍혀 버려진다.**
   트레이는 한 종류만 들어가므로 소프트웨어로는 못 피한다. **2쪽 건의 용지 운영을 먼저 정하고 켜라.**

**㉝-1 크롬만 검증하면 실제 인쇄 경로를 못 본다**
`verify-print.py` 의 기본값은 데스크톱 크롬 `--print-to-pdf` 인데, **실제 인쇄는 Electron 을 지난다.**
㉝ 이 정확히 그 틈으로 빠져나갔다 — 크롬 기준선은 19쪽 전부 0px 인데 인쇄물만 어긋나 있었다.
→ 인쇄 옵션·Electron 버전·인쇄 CSS 를 건드렸으면 **`--electron` 도 함께** 돌린다. 기준선은 하나이고,
두 경로가 같은 결과를 내야 한다는 것이 요지다(그래서 `--electron --update` 는 막아 두었다).
※ 두 크로미움 빌드의 글자 안티에일리어싱 차이로 몇백 px 가 다를 수 있어 `ELECTRON_PX_TOL`(2000px)을 둔다.
**조판이 어긋나면 자릿수가 다르다** — 기준선을 1px(0.17mm)만 밀어도 66,000~300,000px 가 달라진다.

## 배포 · 동기화

**㉑ 배포 HTML은 사본이 하나 있다**
루트(원본) / `kiosk-app/app/`. (2026.08 이전에는 `키오스크배포/` 까지 3곳이었다 — 크롬 방식 폐지로 줄었다.)
→ 항상 루트만 고치고 `bash tools/sync-kiosk.sh`, 커밋 전 `--check`.

**㉑-1 `make-manual.py` 의 마크다운은 부분집합이다 — 조판이 조용히 어긋난다**
지원: `#`~`###` · 표 · `-`/`1.` 목록(1단 중첩) · `>` 인용 · ` ``` ` 코드블록 · `**굵게**` · `` `코드` `` · `![](fig:이름)`.
**미지원: `*이탤릭*`** — 별표가 그대로 찍힌다.
한 항목이 **여러 줄인 목록**은 원래 이어짐 줄이 목록 밖 문단으로 떨어져 나갔다(2026.08.07 수정 — 이제 이어 붙인다).
→ 새 운영문서를 쓰기 전에 이 목록을 확인하고, **만든 PDF는 한 번 열어 눈으로 보라.** 오류 없이 이상하게 나온다.

**㉒ 엔진(`engine.js`·`base.html`)을 고치면 엔진 서식 5종을 전부 재빌드해야 한다**
안 하면 손작성 3종만 바뀌어 8종 동작이 갈린다. 재빌드에는 `engine/assets/*.b64` 가 필요하고
이 파일은 `.gitignore` 이므로, 없으면 `python tools/prep-bg.py <이름> 서식원본/<서식.pdf>` 로 먼저 만든다.

**㉓ PowerShell 로 저장한 설정 파일은 BOM 때문에 앱이 못 읽는다**
`Set-Content -Encoding UTF8`(PS 5.1)은 BOM 을 붙이는데, Node 의 `JSON.parse` 는 BOM 이 붙으면 던진다.
그러면 키오스크가 "프린터 미지정"으로 판단해 **인쇄를 안 한다**(설정은 분명히 했는데).
→ `[IO.File]::WriteAllText(..., (New-Object Text.UTF8Encoding($false)))` 로 **BOM 없이** 쓰고,
읽는 쪽(`main.js`)에서도 `replace(/^﻿/, '')` 로 한 번 더 막는다. 양쪽 다 해 둘 것.
※ 반대로 **`.ps1` 소스 자체는 BOM 이 필요하다**(㉕) — 헷갈리기 쉽다.

**㉔ 줄바꿈이 파일마다 다르다**
`engine/base.html` 은 CRLF, 손작성 3종은 LF. 그래서 `init();\n</script>` 로 매칭하면 CRLF 파일에서 **조용히 0건**.
`.gitattributes` 로 `*.sh` = LF(안 그러면 스크립트가 깨진다), `*.bat`·`*.ps1` = CRLF 고정.

**㉔-1 `git checkout -- .` 뒤에 `sync-kiosk.sh --check` 가 갑자기 드리프트를 보고한다**
이 리포는 `core.autocrlf=true` → 체크아웃하면 루트 HTML이 **전부 CRLF로 다시 써진다.**
배포 사본(`kiosk-app/app/`)은 예전 줄바꿈을 유지하고 있어 **바이트만** 달라진다
(git 은 정규화해서 비교하므로 "변경 없음"으로 본다 — 즉 커밋 내용은 동일하고 인쇄물도 0px).
→ `bash tools/sync-kiosk.sh` 한 번으로 정리된다. 되돌린 셈이 아니라 **원래 파일이 손실된 것이 아님**을 먼저 확인할 것.

**㉔-2 `git status` 가 고치지도 않은 파일을 `M` 으로 표시한다**
줄바꿈이 바뀌어 stat 캐시가 어긋난 것. `git diff` 는 아무것도 안 보여 주고,
`git ls-files -s <파일>` 의 해시와 `git hash-object --path=<파일> <파일>` 이 같으면 **내용은 동일**하다.
`git add` 를 해 보면 스테이징 목록에서 사라진다. 겁먹지 말 것.

**㉕ 한글이 많은 `.bat` + `chcp 65001` 은 cmd가 줄을 잘못 읽는다**
실제로 usage 블록의 한 줄이 사라지고 `'.bat' is not recognized` 가 났다.
→ **`.bat` 은 ASCII 런처만, 로직·한글 메시지는 `.ps1`**(UTF-8 **BOM 필수** — PS 5.1은 BOM 없으면 ANSI로 오독).
`.bat` 은 절대경로로 호출하고, 출력 확인은 `subprocess` + **cp949 디코드**.

**㉖ 가상 프린터 판별은 포트 기준으로 한다**
**`Microsoft Print to PDF` 만 막아선 부족하다** — 시청 PC엔 `Hancom PDF`(포트 `Hancom PDF Port`)도 있다.
판별은 **포트 기준**(`PORTPROMPT:`·`SHRFAX:`·`nul:`) + 알려진 이름 목록으로 하고,
⛔ **DriverName 에 'PDF' 매칭은 금지**(실물 프린터 드라이버명에 PDF가 들어갈 수 있어 실물이 지워진다).
애매한 것은 지우지 말고 "확인이 필요한 프린터"로 알려만 준다.
같은 목록이 `kiosk-app/main.js`(인쇄 직전 거부)와 `admin/kiosk-privacy.ps1`(제거) **양쪽에** 있다 — 한쪽만 고치지 말 것.

**㉖-1 인쇄 보호 장치는 '안 걸리면 그냥 열린다'로 만들면 안 된다**
`window.print` 를 무음 인쇄로 바꿔 끼우는 방식은, 주입이 실패하면 **원래의 네이티브 인쇄 대화상자가 그대로 남는다.**
거기서 `Hancom PDF` 를 고르면 개인정보가 파일로 남는다 — 2026.08 보안성 검토에서 실제로 지적됐다.
→ 주입 결과를 **되읽어 확인**하고, 안 걸렸으면 `admin/fatal.html` 로 멈춘다(fail-closed).
프린터 미지정·가상 프린터·비정상 상태도 전부 **인쇄를 안 하는 쪽**으로 처리한다.

**㉖-2 인쇄 대기열에 남은 작업은 개인정보다**
프린터를 일시중지해 두면 스풀 파일(`C:\Windows\System32\spool\PRINTERS`)에 렌더링된 서식이 그대로 쌓인다.
프린터 속성의 **[인쇄된 문서 유지]** 가 켜져 있으면 정상 인쇄 후에도 남는다.
→ 인쇄 전 상태 점검(`PrinterStatus -ne 'Normal'` 이면 거부) + 인쇄 후 잔여 작업 회수 + `KeepPrintedJobs $false`.

**㉗ 이 설정 스크립트를 적용·되돌리기 모드로 실행하면 실제로 프린터가 삭제된다**
→ 점검은 `/preview`·`/status` 로만.

## 화면 · 로고

**㉘ 로고 흰색 버전을 `filter:brightness(0) invert(1)` 로 만들면 글자가 사라진다**
민트 띠가 흰색이 되면서 그 위의 흰 "YOU" 가 같이 희어진다.
→ **민트→흰색·흰색→투명**으로 다시 칠한 반전본을 쓴다(`newAlpha = alpha × invert(R채널)`).
`tools/embed-logo.py` 가 이 처리를 한다.

**㉙ 제목 넘침을 `scrollWidth > clientWidth` 로 판정하면 안 된다**
`padding-right` 가 `clientWidth` 에 포함돼, 제목이 로고 아래로 파고들어도 '안 넘침'으로 나온다.
→ `Range.selectNodeContents` + `getBoundingClientRect().width` 로 실제 글자 폭을 재서 `clientWidth - padding` 과 비교한다.

**㉚ 구형 헤드리스는 창 폭을 ~469px 로 클램프한다**
모바일 스크린샷이 잘린 것처럼 보이지만 실제 폰(390px)은 정상 리플로우된다.
→ 모바일 캡처는 폭 ≥ 500 으로 찍는다.

**㉜ 키오스크에서 네이티브 `confirm`·`alert` 을 쓰면 화면이 **먹통**이 된다 — 브라우저에서는 멀쩡하다**
네이티브 대화상자는 Win32 모달이라 부모 창을 **비활성 상태(`isEnabled=false`)** 로 만든다.
그런데 `main.js` 의 화면 이탈 방지 조치(`blur` → 첫 화면으로 초기화 + `focus()`)가 그것을 이탈로 오인해
포커스를 도로 가져간다. 결과는 **포커스는 있는데 입력은 막힌** 상태 — 클릭도 키도 전부 무시된다.
게다가 대화상자는 `alwaysOnTop('screen-saver')` 전체화면 뒤로 밀려 눌러서 닫을 수도 없다.
실측(2026.08.08):

```
[대화상자 뜨기 전]      isEnabled=true   isFocused=true
[confirm 이 떠 있는 동안] isEnabled=false  isFocused=false
[focus() 를 호출한 뒤]   isEnabled=false  isFocused=true   ← 먹통
```

→ **서식에서는 네이티브 대화상자를 절대 쓰지 마라.** 예/아니요는 `askConfirm(메시지, 함수)`,
안내는 `window.__printNotice`(⑳). 둘 다 페이지 안 요소라 이 문제가 없다.
→ `main.js` 의 `blur` 핸들러는 `win.isEnabled()` 로 대화상자 여부를 판별해 건너뛴다(이중 안전장치).
`isEnabled()` 가 이 판별에 쓸 수 있다는 것은 위 실측으로 확인했다.
⚠️ **브라우저(GitHub Pages)에서는 재현되지 않는다.** 키오스크 exe 로만 드러나므로,
화면 동작을 고쳤으면 포터블로 한 번 띄워 보는 편이 안전하다.
⚠️ `askConfirm` 은 **엔진과 손작성 3종에 각각 있다** — 한쪽만 고치지 말 것(㉒).

## 서식 지식 (사실 확인 결과 — 임의로 바꾸지 말 것)

- **미성년자도 사증면수 26면/58면 선택 가능**하다. 고정은 유효기간 5년뿐. "미성년은 26면 고정" 요청이 다시 오면 이 사실을 먼저 제시한다(외교부 여권안내 확인).
- **만 8세 미만도 유효기간 5년**이다. `5년 미만` 은 병역 등 특수 사유용이고 연령 기준이 아니다.
- **긴급여권** = 1년 단수·비전자·12면 고정(면수 선택 없음).
- **관용·외교관 여권**은 일반 신청 대상이 아니다(소속기관 경유).
- 여권 첨부 매트릭스: 성인 본인 = 없음 / 성인 대리 = **위임장** / 미성년(본인·대리 무관) = **법정대리인 동의서**.
