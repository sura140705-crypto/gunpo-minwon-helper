## 1. 이번 차례에 부탁드리는 것 — **디자인 철학**

구체적인 CSS 값이 아니라, **원칙**을 세워 주십시오.

- 이 화면이 **무엇을 위해** 존재하는지 (한 문장으로)
- 그래서 **무엇을 먼저 보이게** 하고 무엇을 뒤로 물릴지 — 위계의 규칙
- 화면 요소들을 부르는 **공통 어휘** (지금은 화면마다 이름이 다릅니다)
- 8종을 하나로 묶을 때 **무엇을 같게 하고 무엇은 달라도 되는지**
- 「하지 않는다」의 목록 — 이 용도에서 쓰면 안 되는 표현·장식

값(px·색·여백)은 **다음 차례에 정합니다**(§3). 지금 값을 주셔도 그때 다시 흔들립니다.
지금 필요한 것은 **그 값을 판단할 기준**입니다.

> 📌 이 철학은 **확대간부회의 자료로 설명될 것**입니다. 그림 없이 말로 옮겼을 때도
> 납득되는 형태 — 「왜 이렇게 생겼는가」에 답할 수 있는 형태였으면 합니다.

## 3. 이 답이 그다음에 어떻게 쓰이는지

답의 **형태**를 맞추시는 데 필요하실 것 같아 적습니다.

```
[지금] 현황 묶음(이 폴더)  →  ① 디자인 철학 정립   ← 여기를 부탁드립니다
                            ↓
                           ② 그 철학대로 화면 구조·문구·흐름을 코딩
                            ↓
                           ③ 확정된 레이아웃과 의도를 주고 CSS 시안 의뢰
                            ↓
                           ④ 받은 CSS 를 원본 9개 화면에 반영
                            ↓
                           ⑤ 설치본으로 묶어 확대간부회의 자료로 제출
```

- ①이 흔들리면 ②③④가 전부 다시 갑니다. 그래서 **원칙을 먼저** 받고 싶습니다.
- ③은 **레이아웃이 확정된 뒤**입니다. ①에서 레이아웃을 못 박아 주실 필요는 없지만,
  **무엇이 한 화면에 같이 있어야 하는가** 정도는 정해 주시면 ②가 흔들리지 않습니다.

## 4. 절대 조건 (여기를 넘으면 답을 쓸 수 없습니다)

| | |
|---|---|
| ⛔ **인쇄물** | 정부 별지서식 이미지 위에 **절대좌표**로 값을 얹습니다. 1pt 밀리면 접수처 스캐너가 못 읽습니다. `@media print { … }` 와 서식 이미지는 대상이 아닙니다 |
| 🎨 **색** | **기관 대표색 하나에서 계산**합니다. 기관마다 다릅니다 — 특정 색을 전제한 안은 쓸 수 없습니다 |
| 🔤 **글꼴** | `"Malgun Gothic"`. 다른 글꼴을 제안하시려면 **설치 없이 쓸 수 있는지** 함께 알려 주십시오 |
| 📴 **오프라인** | Electron 설치본입니다. **외부 CDN·웹폰트·아이콘 세트를 쓸 수 없습니다**(그래서 아이콘이 전부 이모지입니다) |
| 👆 **입력** | 터치로 고르고, 글자는 **물리 키보드**로 칩니다. 화면 키보드는 쓰지 않기로 했습니다 |
| 👵 **사용자** | 민원실에 온 시민. 어르신 비중이 높고, **서서·뒤에 사람이 기다리는 채로** 3~10분 |
| 🖥️ **화면** | 1920×1080 가로가 기본. **1080×1920 세로**로 놓는 기관도 있습니다 |
| 🏢 **다기관** | 기관마다 취급 서식이 다릅니다. **카드가 8장인 곳도, 4장인 곳도** 있습니다 |
