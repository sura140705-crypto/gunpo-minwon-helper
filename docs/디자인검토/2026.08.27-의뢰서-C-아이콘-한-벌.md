# 여기서부터가 AI에게 주는 내용입니다

## 1. 무엇에 쓰는 아이콘인가

군포시 민원실 **창구 옆에 놓인 키오스크**입니다. 시민이 질문에 답하면 정부 공식 신청서가
채워지고, 종이로 인쇄해 창구에 냅니다.

첫 화면에 **민원 8종이 세로 목록**으로 있고, 각 줄 왼쪽에 아이콘이 하나씩 붙습니다.
상단 바에 도구 단추가 두 개 더 있습니다. **모두 10개**입니다.

| | |
|---|---|
| **크기** | 화면에서 **21px**(카드) · **16px**(단추). 격자는 24 |
| **거리** | **서서** 봅니다. 앉아서 보는 웹사이트가 아닙니다 |
| **쓰는 사람** | 민원실 방문 시민. **고령자가 많습니다** |
| **역할** | 아이콘만으로 뜻이 전달될 필요는 **없습니다.** 옆에 큰 글씨가 있습니다.<br>목록을 훑을 때 **자리를 잡아 주는 것**이 주된 일입니다 |

## 2. 절대 조건 — 여기를 넘으면 답을 쓸 수 없습니다

| | |
|---|---|
| 📴 **오프라인** | Electron 설치본입니다. **아이콘 폰트·아이콘 세트·CDN·이미지 파일을 쓸 수 없습니다.**<br>코드 안에 넣는 **인라인 SVG `path`** 여야 합니다 |
| 📐 **한 벌** | `viewBox="0 0 24 24"` · `fill="none"` · `stroke-width="1.7"` · `stroke-linecap/linejoin="round"`<br>⛔ 채움(fill) 아이콘과 선(stroke) 아이콘을 섞지 마십시오 |
| 🎨 **단색** | `currentColor` 하나입니다. ⛔ **여러 색을 쓸 수 없습니다** — 기관마다 대표색이 다르고, 색에는 이미 다른 역할이 있습니다 |
| 🕊 **감정** | **사망·이혼은 감정이 실리는 민원입니다.** ⛔ 십자가·비둘기·영정·깨진 하트·눈물처럼 세게 읽히는 상징을 쓰지 마십시오 |
| 🖥 **성능** | 재사용 사무용 PC. ⛔ 그라데이션·필터·마스크·`stroke-dasharray` 애니메이션 금지 |
| 👀 **21px** | 그 크기에서 형태가 뭉개지면 탈락입니다. **획이 6~8개를 넘지 않는 편**이 안전합니다 |

### 우리가 스스로 의심하는 곳 (여기부터 봐 주시면 좋겠습니다)

1. **`death`(국화)** — 21px 에서 원 다섯 개가 뭉개져 보일 수 있습니다. 획이 가장 많습니다.
2. **`divorce`(두 사람 + 끊긴 선)** — 24 격자에 사람 둘이 들어가 답답합니다. 끊긴 선이 21px 에서 보입니까?
3. **`birth`(머리 큰 사람)** — `divorce` 의 사람과 형태가 겹쳐, 목록에서 두 줄이 비슷해 보입니다.
4. **`cert`(문서 + 관인)** — 획이 많고, 관인 원이 문서 테두리에 붙습니다.
5. **`marriage` 의 보석** — 없어도 되는 장식인지, 있어야 「반지」로 읽히는지.

## 4. 무엇을 부탁드리는가

**전부 다시 그려 오라는 것이 아닙니다.**

- **더 나은 안이 있는 것만** 주십시오. 나머지는 「그대로」라고 적어 주시면 됩니다.
- 하나도 바꿀 것이 없으면 **「전부 그대로 두십시오」**라고 답해 주셔도 됩니다. 그것도 결과입니다.
- ⚠️ 다만 **한 벌은 통째로 갈아 끼웁니다.** 한두 개만 다른 손으로 그리면 한 벌이 아니게 됩니다.
  그러니 **셋 이상을 고치실 거면 열 개를 다** 주십시오. 둘 이하면 그것만 주십시오.

## 5. 답변 형식 — **이 형식으로만** 주십시오

⛔ **이미지·PNG·SVG 파일·아이콘 세트 링크·폰트 제안을 주지 마십시오.** 붙일 자리가 없습니다.
필요한 것은 **`path` 문자열**입니다.

```markdown
## 요약
(3줄 이내. 무엇을 왜 바꿨는지 · 몇 개를 바꿨는지)

## 판정
| 키 | 지금 | 판정 | 왜 |
|---|---|---|---|
| passport | 책자+사진 | **그대로** | 21px 에서 읽힘 · 다른 것과 안 겹침 |
| death | 국화 5원 | **고침** | 21px 에서 원이 붙어 뭉개짐 |

## 새 path (고친 것만, 또는 전부)
```
death   <path d="..."/><circle .../>
```

## 21px 에서 무너지지 않는 근거
(획 수 · 최소 간격 · 겹치는 형태 회피를 어떻게 다뤘는지 — 한두 줄)

## 넘기지 못한 것
(제약 때문에 제안하지 못했지만 짚고 싶은 것. 없으면 「없음」)
```

- 좌표는 **24 격자 안**에 있어야 합니다. 넘으면 잘립니다.
- `stroke-width` 를 개별 아이콘마다 다르게 주지 마십시오. **1.7 고정**입니다.
- 획 끝은 전부 `round` 입니다. 그것을 전제로 좌표를 잡아 주십시오.

## 6. ⛔ 받지 않는 답

| | |
|---|---|
| 이모지로 되돌리는 안 | OS·글꼴마다 모양이 달라지고, 여러 색을 씁니다. **그래서 걷어낸 것입니다** |
| 아이콘 폰트·세트(Material·Feather·Lucide…) | 설치·CDN 이 필요합니다. **오프라인입니다** |
| 색을 쓰는 안 | 대표색이 기관마다 다르고, 색에는 이미 다른 역할이 있습니다 |
| 채움(fill) 아이콘 | 지금 화면은 선 위주입니다. 섞으면 한 벌이 아닙니다 |
| 애니메이션이 붙은 아이콘 | 대기 시연 말고는 움직이지 않습니다 |
| 「더 모던하게」 같은 말 | 붙일 수 없습니다. **좌표를 주십시오** |

## 7. 답을 고르는 기준 (의뢰하는 쪽이 읽는 곳)

앞의 셋에서 떨어지면 나머지는 볼 것도 없습니다.

| # | 기준 | 떨어지면 |
|---|---|---|
| 1 | **`path` 문자열로 왔는가** (24 격자·굵기 1.7·선) | 붙일 수 없습니다. 탈락 |
| 2 | **오프라인에서 되는가** (폰트·세트·외부 파일 없음) | 현장에서 안 뜹니다. 탈락 |
| 3 | **사망·이혼에 세게 읽히는 상징을 쓰지 않았는가** | 민원인이 상처받습니다. 탈락 |
| 4 | **21px 로 줄여 봤을 때 형태가 남는가** | 실제로 줄여 보고 판정하십시오 |
| 5 | **열 개가 한 벌로 보이는가** | 획 굵기·모서리·여백이 따로 놀면 안 됩니다 |
| 6 | **지금 것보다 나은가** | 「다르다」는 「낫다」가 아닙니다. 그대로 두는 것도 답입니다 |
