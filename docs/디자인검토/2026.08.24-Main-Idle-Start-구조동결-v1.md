여권 Reference UI 를 기준으로 **Main → Writing** 을 하나의 연속된 경험으로 설계하고,
그 **구조·정보위계·전환 규칙**을 여기서 동결한다.

> ⚠️ **화면은 이제 MAIN 하나다.** START(v2)에 이어 **IDLE 도 별도 화면을 두지 않는다**(v3).
> 파일 이름에는 아직 `Idle`·`Start` 가 남아 있다 — 다른 문서 여럿이 이 이름으로 이 파일을
> 가리키고 있어 바꾸지 않았다.

# 1. 상태와 흐름

```
MAIN → WRITING → REVIEW → PRINT → SESSION CLEAR → MAIN
선택     작성       확인      출력      비움
 └ 아무도 안 건드리면 여기서 **시연**이 돈다 (별도 화면이 아니다)
```

시민의 **의도가 점점 구체화되는 하나의 제품**이다.
⛔ 서로 다른 여러 개의 웹페이지처럼 만들지 않는다.

| 상태 | 한 일 | ⛔ 하지 않는 일 |
|---|---|---|
| **MAIN** | 작성할 서식을 고르게 한다.<br>아무도 안 건드리면 **스스로 시연해 「써도 된다」를 알린다** | 시정홍보 · 캐러셀 · 개인정보 입력 |
| ~~IDLE~~ | **폐기(v3).** 화면이 아니라 **MAIN 의 한 상태**다 — §3-1 | |
| ~~START~~ | **폐기(v2).** 아래 상자를 보라 | |
| **WRITING** | 질문에 답하게 한다 | (동결된 Reference UI) |

> ### IDLE 을 별도 화면으로 두지 않는 이유 (2026.08.25)
>
> 철학 §22 가 대기 화면에 요구하는 것은 하나다 —
> **「이것은 시민이 지금 사용할 수 있는 도구다」를 알릴 것.**
> 그리고 「Idle 에서 실제 서비스로 넘어갈 때 다른 제품으로 바뀐 것처럼 느껴지지 않을 것」.
>
> **뒤엣것은 화면을 나누지 않으면 저절로 지켜진다.** 그리고 앞엣것은
> **쓰는 모습을 그대로 보여 주는 것**보다 잘 알리는 방법이 없다 — 가상 신청서 한 장이
> 저절로 채워지는 것보다, 왼쪽 목록이 하나씩 짚히고 오른쪽 진짜 서식이 바뀌는 편이
> 「여기서 무엇을 할 수 있는가」까지 같이 말한다.
>
> ⛔ **되살리지 마라.** 되살리면 ① 이을 화면이 하나 늘고 ② 가상 종이(Generic Paper)를
>    다시 만들어야 하고 ③ 「깨어남」이라는 전환을 새로 설계해야 한다. 셋 다 이제 없다.

> ### START 를 없앤 이유 (2026.08.24)
>
> Start 가 하려던 일은 셋이었다 — ① 고른 것을 되짚어 주고 ② 얼마나 걸리는지 알리고
> ③ 준비물을 말한다. **그 셋 다 화면 하나를 더 세울 만한 일이 아니었다.**
>
> - ①은 MAIN 에서 고른 카드가 `picked` 로 남고 **오른쪽에 그 서식의 실제 1쪽이 이미 떠
>   있어서** 이미 이뤄진다. 고르기 전부터 「무엇을 쓰게 되는지」가 보인다.
> - ③의 준비물은 **경로가 정해져야 정확해진다**(성인/미성년·본인/대리). 그 판단은 각
>   서식의 `SCREENS.ready` 가 이미 하고 있었다. Start 는 「경로 무관 공통분」만 말할 수
>   있었는데, 그러면 **두 곳에서 두 번 말하게 된다.**
> - 남는 것은 ②뿐이다. 그 한 줄 때문에 시민이 **누름을 한 번 더** 해야 했다.
>
> ⛔ **되살리지 마라.** 되살리려면 위 셋이 왜 다시 필요한지부터 뒤집어야 한다.
> ⚠️ 여권의 `SCREENS.ready` 는 그대로 둔다. Start 의 대체물이 아니라 **원래 자기 일**이다.

# 2. 공통 골격 — 네 구역, 배치 하나

모든 상태가 **같은 네 구역**을 쓴다. 상태가 바뀌면 구역이 생기거나 사라지는 것이 아니라
**내용만 바뀐다.**

| 구역 | 하는 일 |
|---|---|
| **BAR** | 상단 바 `--topbar-h`(74px). 로고·기관명·서식 이름·도구. **한 번도 사라지지 않는다** |
| **ASK** | 지금 시민에게 말을 거는 곳 |
| **PAPER** | 종이. **연속성의 축**(§6) |
| **RAIL** | 참조 정보. 안심 안내는 **바닥 고정**(§7) |

```
배치 2  MAIN(시연 포함) · WRITING    BAR + ASK / PAPER / RAIL     = --cols
```

⚠️ **배치는 하나뿐이다(v3).** 배치 1(ASK 위 / PAPER 아래 띠)은 v2 에서, 배치 0(대기)은
v3 에서 없앴다. **화면 하나에 배치 하나**이므로 「전환」을 설계할 일이 남지 않았다 —
페이지가 실제로 교체되는 곳은 MAIN→WRITING 한 군데뿐이고, 둘의 기하가 같아 화면이
움직이지 않는다. ASK 는 질문·목록에서 질문·입력으로, PAPER 는 빈 서식에서 채워지는
서식으로 **내용만** 바뀐다.
⛔ 배치를 늘리지 마라. 하나를 더하는 순간 이을 자리가 생긴다.

⛔ **네 구역은 무슨 일이 있어도 생성·삭제되지 않는다.** 바뀌는 것은 **내용**뿐이다.
   시연 중에도 RAIL 은 그대로 있고, 카드가 펼쳐져도 ASK 구역 안에서 열린다.

⚠️ **배치 2 는 동결된 Writing 의 `--cols` 토큰을 그대로 쓴다.**
`--cols` 는 2026.08.24 에 고정폭을 버리고 **비율**이 됐다 — 일반 2:3:1 · 크게 보기 5:5:2.
1920 기준 일반 보기 **ASK 640 / PAPER 960 / RAIL 320**.

## 3-1. ~~IDLE — 발견~~ → **MAIN 의 시연 상태** (v3)

> ✅ **구현됨**(2026.08.25, `index.html`). 아래가 지금 코드다.
> ⛔ v1·v2 의 「배치 0 · Generic Paper · 깨어남」 설계는 **폐기했다** — §1 의 상자를 보라.

```
┌─ BAR ─ 로고·기관명 ─────── 오늘 날짜 ────── 🔍 크게 보기 ──────┐
├──── ASK 640 ──────────┬──── PAPER 960 ────┬─── RAIL 320 ────┤

│ 고르시면 오른쪽에       │ │               │ │ 도와드립니다      │
│ 그 신청서가 나타납니다   │ │  혼인신고서     │ │ 1 왜 묻는지      │
│                       │ │               │ │ 2 쉬운 말로      │
```

**정보 위계** ① 여기서 무엇을 할 수 있는가(카드가 하나씩 짚힌다)
② 그러면 무엇이 나오는가(오른쪽 진짜 서식이 바뀐다) ③ 지금 만져도 된다 ④ 기관 표기(작게)

| | |
|---|---|
| **한 카드에 머무는 시간** | **2.8초.** 8종이면 한 바퀴 22.4초 — 다섯 줄을 읽을 시간이다 |
| **움직이는 것** | **강조 하나와 가운데 종이뿐** |
| ⛔ **금지** | 캐러셀 · 시정홍보 · 빠른 pulse · 카드 펼침판을 여닫는 것(§아래) |
| **끄는 것** | `pointermove`·`pointerdown`·`keydown`·`wheel`·`touchstart` — **무엇으로든** |
| **다시 켜지는 때** | 아무 조작 없이 `idleMs`(기본 3분)가 지나면 |
| **감소 모션** | `prefers-reduced-motion` 이면 **아예 돌지 않는다.** 기본 상태 그대로 둔다 |

- ⛔ **시연이 짚는 카드에 「골라짐」 표시를 쓰지 않는다.** 시연이 끝난 뒤에도 시민이 고른
  것처럼 남는다 — 고르지도 않은 것이 골라져 있으면 안 된다. 코드에서도 `.picked` 가 아니라
  `.demo-on` 이라는 **다른 이름**을 쓰고, 끝날 때 전부 지운다.
- ⛔ **시연이 카드 펼침판까지 열지 않는다.** 열고 닫을 때마다 아래 카드들이 밀려내려가
  목록 전체가 출렁인다. 대기 화면은 조용해야 한다(철학 §22).
- ⚠️ **시연이 끝나면 「기본 상태」로 간다** — 아무것도 골라지지 않고 종이 자리는 비어 있다.
  시연이 짚던 것을 골라진 것으로 넘겨주지 않는다.
- ⚠️ CSS 의 `prefers-reduced-motion` 규칙은 transition/animation 만 끈다.
  **JS 로 도는 시연은 `matchMedia` 로 직접 갈라야 한다**(여권 `calmScroll()` 과 같은 방식).
- ⚠️ 시연이 막 시작하면 커서 아래 요소가 바뀌어 브라우저가 `mousemove` 를 **합성한다.**
  그것에 즉시 꺼지지 않도록 시작 직후 0.4초는 움직임만 무시한다.

### ⚠️ Generic Paper 는 폐기했다 (v3)

v1·v2 는 대기 화면에 **가상 신청서**(○○○ 신청서 + 추상 획 + Print Marker)를 두었다.
시연이 실제 서식을 돌려 보여 주므로 **더 이상 쓸 곳이 없다.**

> 가상 종이는 「종이가 채워진다」만 말했다. 실제 서식은 그 위에 **「무엇을 쓰게 되는지」**
> 까지 말한다. 「실제 작성 경험과 연결되는 Paper」(철학 §22)에 이쪽이 더 가깝다.

⛔ 되살리지 마라. 되살리면 개인정보처럼 보이지 않게 하는 규칙(옛 §4)이 통째로 따라온다.

### 첫 상태는 **비어 있다** (v3)

종전에는 첫 서식(여권)이 이미 `picked` 로 떠 있었다. hover 없는 터치에서 종이가 안 보이는
것을 막으려던 것인데, **시민이 고르지도 않은 것이 골라져 있는 셈**이라 「지금 무엇을 보고
있는가」가 헷갈렸다. 이제 그 자리는 **「서식을 골라 주세요」**가 맡는다.

- ⛔ **hover 에만 의존하지 않는 원칙은 그대로다**(2026.08.24 결정 §2). 터치에서 빈 화면이
  되지 않게 **빈 자리가 말을 건다** — hover 로만 아는 정보를 만들지 않았다.
- ⚠️ hover·키보드 포커스는 **아무것도 안 골랐을 때만** 미리보기를 바꾼다.
  펼쳐 놓은 카드가 있으면 그것을 이긴다 — 열어 둔 것을 hover 가 가려서는 안 된다.

### 카드를 눌러도 **바로 넘어가지 않는다** (v3)

누름 한 번에 페이지가 바뀌면 **잘못 누른 사람이 되돌아올 길이 없다.**
카드는 그 자리에서 펼쳐 설명·걸리는 시간·준비물을 내고, **[작성 시작]을 눌러야** 간다.

> 이것이 폐기된 START 가 하려던 일(§1)을 **화면을 늘리지 않고** 하는 방법이다.
> 카탈로그의 `desc`·`ready`·`scale` 이 여기서 다시 쓰인다(§10 의 「읽는 곳이 없어졌다」는
> v3 에서 해소됐다).

- ⛔ **막지 않는다.** 준비물이 없어도 [작성 시작]으로 갈 수 있다
- ⚠️ **없는 것을 지어내지 않는다.** `ready`·`scale` 이 비면 그 줄을 아예 내지 않는다 —
  지금은 **여권만** 채워져 있고 나머지 7종은 설명 한 줄이다
- ⚠️ 한 번에 **하나만** 열린다. 같은 카드를 다시 누르면 접히고 종이 자리도 비워진다
- ⚠️ 카드는 `<button>` 이라 그 **안에** [작성 시작]을 넣을 수 없다(단추 안의 단추).
  `.card-wrap` 으로 감싸고 펼침판을 **형제로** 둔다
- ⚠️ 여는 높이는 `grid-template-rows: 0fr → 1fr` 로 잰다.
  ⛔ `max-height` 추측값을 쓰지 마라 — 준비물이 긴 여권에서 내용이 잘린다

### 그 밖의 규칙

- 카드는 **세로 한 열**. 8개를 한눈에 훑는 자리라 여권의 두 칸 격자(`--touch-card` 132px)
  대신 `--row-h`(66px)를 쓴다. 폭이 넓어 표적 넓이는 `--touch-min` 을 크게 넘는다
- **PAPER 는 고른 서식의 실제 1쪽이다**(§4 정정)
- ⛔ 「이용 가능 / 준비 중」 배지는 쓰지 않는다 — 전부 같은 값이면 정보가 아니라 소음이다(§14)
- 보조 분류(`category`)는 **화면에 드러내지 않는다.** 20종 이하에서는 1차 탐색을 강제하지 않는다
- ⚠️ `[hidden]` 은 브라우저 기본 규칙이라 **클래스의 `display` 에 진다.** `display` 를 직접
  주는 요소는 `[hidden]{display:none}` 을 같이 적어야 한다 — 빠뜨려서 감춘 것이 화면에
  그대로 남은 일이 있었다(2026.08.25)

# 5. 시연 규격 (동결)

> ⚠️ **v3 에서 통째로 바뀌었다.** 옛 규격은 가상 종이의 칸이 채워지는 시연이었다.

| | |
|---|---|
| **한 카드** | **2.8초.** 8종이면 한 바퀴 22.4초 |
| **보여 주는 것** | 카드 강조 하나 + 종이 갈아끼우기(0.34초 흐림) + **값이 한 줄씩 채워짐**(줄당 0.34초·간격 0.46초) |

# 6. Paper Lifecycle (동결) — 연속성의 축

| 상태 | 위치 | 내용 | 움직임 |
|---|---|---|---|
| **MAIN — 시연** | CENTER | 짚고 있는 서식의 **실루엣**(항목 이름 + 채워지는 값) | 2.8초마다 갈아끼움(§5) |
| **MAIN — 기본** | CENTER | **비어 있다**(「서식을 골라 주세요」) | 정지 |
| **MAIN — 고름** | CENTER | 고른 서식의 **실제 1쪽** | 정지 |
| **WRITING** | CENTER | 고른 서식 | Current Focus 이동 + 값 채워짐 |
| **REVIEW** | CENTER | 다 채워진 서식 | 정지 |
| **PRINT** | — | 종이가 화면을 떠난다 | |
| **CLEAR** | — | 아무것도 없다 | |

> **한 바퀴가 종이의 여정이다.**
> 여러 장이 스쳐 간다 → 한 장이 골라진다 → 채워진다 → 다 찬다 → 프린터로 간다 →
> 치워진다 → 다시 스쳐 간다

⚠️ **종이는 자리를 옮기지 않는다**(v3). v1·v2 에서는 「중앙 대형 → CENTER 로 앉는다」가
연속성을 담당했는데, 대기 화면이 없어지면서 **옮길 자리 자체가 없어졌다.**
연속성은 이제 **종이가 늘 같은 자리에 있다는 사실**이 담당한다.

### 다시 시연으로 돌아오는 길

| | |
|---|---|
| **8종에서** | 무동작·인쇄 뒤 `index.html` 로 돌아온다(엔진의 개인정보 보호 블록). 허브는 시연부터 시작한다 |
| **허브에서** | 아무 조작이 없으면 시연이 다시 돈다 |
| **대기 시간** | 키오스크 환경설정의 `idleMs`(기본 3분). ⚠️ **서식 8종과 같은 값을 쓴다** — 창구에서 두 가지를 따로 맞출 일이 없게 한다 |
| **끄는 것** | `pointermove`·`pointerdown`·`keydown`·`wheel`·`touchstart` — 무엇으로든(철학 §19) |

⚠️ 허브에는 지울 개인정보가 없다. 이 시계는 **보호가 아니라 시연으로 돌아가기 위한 것**이다.
그래서 서식 8종처럼 **30초 경고를 띄우지 않는다** — 잃을 것이 없는데 경고하면 소음이다.
⚠️ `pointermove` 는 초당 수십 번 온다. **1초에 한 번만** 시계를 되감는다.

# 7. RAIL 규칙 (동결)

```
[상단]  작성 진행          WRITING 부터
[중단]  준비하셨나요?       WRITING 의 각 서식이 맡는다 (v2 — Start 가 없어졌다)
[대체]  이렇게 도와드립니다   MAIN 에서 — 위 둘이 없을 때 그 자리를 채운다
[하단]  안심하고 작성하세요   MAIN~REVIEW 항상 · 바닥 고정
```

1. **하단(안심 안내)은 어떤 상태에서도 같은 자리에 있다.** `margin-top:auto` 로 이미 그렇다.
2. **위쪽은 상태가 바뀔 때만 바뀐다.** 같은 상태 안에서 질문이 넘어갈 때는 **숫자만** 변한다.
   → §10 「질문이 바뀔 때마다 정보 전체가 바뀌지 않는다」를 이것으로 지킨다.
3. ⛔ **RAIL 영역을 생성·삭제하지 않는다.** 시연 중에도, 카드를 펼쳐도 **그대로 있다.**
   ⚠️ v1·v2 의 「IDLE 에서 RAIL 을 접는다」는 없어졌다 — 접을 상태 자체가 사라졌다.

|---|---|---|---|
| MAIN (시연 포함) | 로고·기관명 | — | 날짜 · 크게 보기 |
| WRITING | 로고·기관명 | 서식 이름 | 서식 목록 · 크게 보기 · 초기화 · 미리보기 · 인쇄 |

1. **왼쪽은 모든 상태에서 한 번도 움직이지 않는다.**
2. 오른쪽 도구는 **필요해질 때 늘어난다.** 줄어들지 않는다.
3. ⚠️ 도구 칸은 `auto`(제 너비)로 두고 **기관명이 먼저 줄어들게** 한다.
   버튼 폭을 깎아 맞추면 기관명이 긴 곳에서 두 줄로 접힌다(2026.08.24 에 겪었다).
4. ⚠️ **시연 중에도 상단 바를 감추지 않는다**(v3). v1·v2 는 대기 화면에서 도구를 숨겼는데,
   시연은 「이 화면을 쓰는 모습」이므로 **평소와 같은 상단 바여야** 앞뒤가 맞는다.

⚠️ **여권 한 종만 이 배치다**(`cfff1a4`). 나머지 7종은 상단 바 골격이 달라
(`flex` + `.brand{margin-right:auto}`) 아직 맞추지 않았다 — 남은 일이다.

# 9. 전환 규칙 (동결) — 무엇이 움직이고 무엇이 남는가

## 시연 → MAIN 기본 (v3)

⚠️ **이것은 「전환」이 아니다.** 같은 화면에서 **시연이 멈출 뿐**이다.

| 움직인다 | 카드 강조가 사라진다<br>PAPER 가 **비워진다** — 「서식을 골라 주세요」로 돌아간다<br>종이 아래 시연 안내문이 사라진다 |
|---|---|
| **그대로** | **BAR 전부 · 네 구역 · 세 영역 폭 · 카드 목록 · RAIL** |
| ⛔ **금지** | 시연이 짚던 것을 **골라진 것으로 넘겨주지 않는다.** 시민이 고른 것이 아니다<br>깨어남 연출·화면 덮개·카드 등장 애니메이션 — **아무것도 덧대지 않는다** |

> v1·v2 는 여기에 「깨어남」이라는 전환을 설계해 두었다. **화면을 나누지 않으니 사라졌다.**

## MAIN → WRITING (실제 페이지 전환)

| 움직인다 | ASK 안의 내용만 「질문 + 목록」 → 「첫 질문 + 입력칸」<br>PAPER 가 미리보기 그림 → **인쇄에 쓰는 진짜 서식**으로 바뀌고 Current Focus 가 첫 칸을 짚는다<br>RAIL 에 「작성 진행」이 더해진다<br>BAR 가운데에 서식 이름이 나타난다 |
|---|---|
| **그대로** | **BAR 왼쪽 · 세 영역 폭 · PAPER 위치와 크기** |
| ⛔ **금지** | **선택한 카드가 날아가거나 확대되어 CENTER 로 이동하는 애니메이션.**<br>카드는 그 자리에서 ASK 전환에 흡수된다 |
| ⚠️ | 실제로는 페이지 교체다(§11). 기하가 같아야 안 보인다 |

## WRITING 내부 (질문 → 질문)

| 움직인다 | ASK 의 질문·입력칸 · PAPER 의 **Current Focus 가 다음 칸으로** |
|---|---|
| **그대로** | BAR · 세 영역 폭 · PAPER 위치 · RAIL 구조(숫자만 증가) |

## WRITING → REVIEW → PRINT → CLEAR → MAIN

| 전환 | 움직인다 | 그대로 |
|---|---|---|
| → REVIEW | ASK 가 질문 → 요약. [다음]이 [신청서 인쇄]로 | BAR · PAPER(다 채워진) · RAIL |
| → PRINT | 인쇄 전 안내가 덮는다(Notice 계열) | 뒤의 골격 |
| → CLEAR | **완전 불투명 덮개** — 아무것도 안 보인다 | (의도적으로 아무것도 안 남긴다) |
| → MAIN | 서식 페이지가 `index.html` 로 돌아가고, **시연이 다시 돈다** | BAR |

⚠️ 마지막 칸은 **실제로 페이지가 바뀐다.** 서식 8종은 무동작·인쇄 뒤 `index.html` 로
이동하고(엔진의 개인정보 보호 블록), 허브는 시연부터 시작한다 — 입력값은 그 이동에서 소멸한다.

# 11. 구현 제약 (동결)

## Main 과 Writing 의 기하를 맞춘다

MAIN 은 `index.html` 안에, WRITING 은 각 서식 HTML 안에 있다.
카드를 누르면 **페이지가 실제로 교체된다.** 전환이 안 보이려면 기하가 같아야 한다.

- `--cols` **같은 토큰**을 쓴다 (1920 기준 일반 보기 ASK 640 / PAPER 960 / RAIL 320)
- `--topbar-h` 74px · PAPER 안쪽 여백 · `width:min(210mm,100%)` 동일
- ⚠️ 허브의 종이는 **미리보기용 축소본**이고 Writing 의 종이는 **인쇄에 쓰는 진짜 서식**이다.
  같아야 하는 것은 **놓이는 자리와 크기**이지 그림 자체가 아니다(§4)

그 위에 **전환 덮개**를 씌워 흰 깜빡임만 가린다.
⚠️ 덮개는 아직 없다 — **남은 일이다.**

## 건드리지 않는 것

- ⛔ **인쇄물** — 절대좌표·`@media print`·서식 이미지·Print Marker
- ⛔ **동결된 여권 Reference UI** — `SCREENS.ready` 포함
- ⛔ **`FORM_KEYS`·환경설정 계약** — `key` 이름을 바꾸지 않는다
