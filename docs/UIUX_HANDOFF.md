## 7-3. 금지 ⛔

| | 왜 |
|---|---|

## 7-4. 지금 구조로는 **구현 불가** ❌

⚠️ **Lovable 이 시안을 줘도 그대로는 못 붙는 것들입니다.** 미리 알려 주십시오.

| 동작 | 왜 안 되는가 | 고치려면 |
|---|---|---|
| 질문 → 다음 질문 전환 | `el.wizBody.innerHTML = h` — **요소가 매번 새로 만들어집니다.** `transition` 이 안 걸립니다 | `@keyframes` 진입 애니메이션 |
| Current Focus 이동 | `.ovhl` 도 `renderForm()` 에서 innerHTML 로 재생성됩니다 | **살아남는 오버레이 하나**로 재구성 ⛔ **인쇄 경로 옆이라 위험** |
| 인쇄 전 안내 모달 여닫기 | `display:none ↔ flex` — `display` 는 전환 대상이 아닙니다 | `opacity` + `visibility` 로 |

## 7-5. 인쇄 · 매핑 · 개인정보에 영향을 줄 수 있는 것 ⛔⛔

| | |
|---|---|
| **Current Focus(`.ovhl`)를 움직이려는 모든 시도** | `renderForm()` 은 **인쇄물을 만드는 것과 같은 함수**입니다 |
| **`.cover` · `.cv` · `.csign-*`** | 종이 위 요소이고 **인쇄물의 일부**입니다 |
| **인쇄 후 덮개(`#printGuard`)** | 📌 **연출을 넣지 않습니다.** 개인정보 차단은 **연출보다 시점**이 먼저입니다 |
| **입력 오류 표시** | 📌 **연출을 넣지 않습니다.** 진행 불가는 지연 없이 보여야 합니다 |

## 9-2. 📌 Ready 의 정의

| | |
|---|---|
| **무엇인가** | **서식별 선택 상태**(Form-specific optional state)입니다 |
| ⛔ **아닌 것** | 공통 Start/Ready **화면**이 아닙니다. 📌 **만들지 않습니다** |
| **여권** | ✅ `SCREENS.ready` 를 **여권의 공식 Ready 로 유지**합니다 |
| **나머지 7종** | 📌 **실제 업무상 필요성이 확인되기 전까지 새로 만들지 않습니다** |
| **Catalog 의 `ready`** | 📌 공통 화면을 만들기 위한 데이터가 **아닙니다.** 서식별 준비정보를 관리하는 **metadata** 입니다. 지금은 카드 펼침판이 그것을 읽어 보여 줄 뿐입니다 |

⚠️ 그래서 「Ready 가 없다」는 것은 **결함이 아닙니다.** 그 서식에 필요하지 않다는 뜻입니다.

## 9-3. ✅ Human Handoff — 지금 코드에 **세 가지**가 있습니다

⚠️ 셋은 서로 **다른 동작**입니다. 이름만 비슷합니다.
