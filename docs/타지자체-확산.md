# 다른 기관이 가져다 쓰는 법 (확산 가이드)

이 도우미의 **서식 좌표맵 8종은 법정 별지서식 기준이라 전국 공통**입니다.
바꿔야 하는 것은 기관 표기·부서·연락처·로고뿐이고, 그 작업은 반나절이면 끝납니다.
좌표를 처음부터 잡는 데 든 시간이 이 프로젝트에서 가장 비쌌으므로, 그 부분을 그대로 재사용하는 것이
확산의 실익입니다.

받는 기관의 상황에 따라 세 가지 중 하나를 고르십시오.

| | 받는 것 | 필요한 역량 | 할 수 있는 것 |
|---|---|---|---|
| **A. 그냥 쓴다** | 설치본(`.exe`) + 운영문서 PDF | 없음(설치·관리자 설정 1회) | 군포시 이름이 그대로 나옴. 시범 체험용 |
| **B. 우리 기관 이름으로 쓴다** | 위 + 이 리포 | Python·Node 설치, 명령 6줄 | 기관명·부서·연락처·로고 교체 (권장) |
| **C. 서식을 늘린다** | 리포 전체 | 위 + 좌표 작업 | 그 기관 고유 서식 추가 |

---

## A. 그냥 써 본다 (설치만)

1. 설치본(`군포민원서식도우미-*.exe`)을 키오스크 PC에 설치 — 전체화면으로 열립니다
2. **`admin/관리자_개인정보보호_설정.bat` 을 관리자 권한으로 1회 실행**
   - `/status` 로 실물 프린터 이름 확인 → `/only "프린터이름"` 으로 지정 → `/pin` 으로 종료 PIN 설정
   - 이 단계를 빼면 **인쇄가 되지 않습니다**(지정 프린터가 없으면 출력하지 않도록 만들어져 있습니다)
3. `군포민원서식도우미.exe --selfcheck` 로 적용 상태를 확인합니다
4. 여백·배율은 프로그램이 고정하므로 따로 맞출 것이 없습니다

자세한 설치·운영은 `운영문서/붙임3_키오스크_설치운영_안내.md`, 창구 직원용 설명은
`운영문서/사용매뉴얼.pdf`(간단본)·`사용매뉴얼_상세.pdf` 입니다.

## B. 우리 기관 이름으로 바꿔 쓴다 (권장)

필요한 것: Python 3(+`pillow`, `pymupdf`), Node.js, 크롬. 기관 로고 PNG(투명 배경 권장).

```bash
# 0) 무엇이 바뀌는지 먼저 본다
python tools/rebrand.py --city 안양시 --dry-run

# 1) 실제 교체 (시·도, 담당 부서, 문의 전화, Electron 패키지명, 로고)
python tools/rebrand.py --city 안양시 --province 경기도 \
       --dept 민원지원과 --tel 031-000-0000 --slug anyang --logo ~/우리기관로고.png

# 2) 로고를 화면에 다시 박고, 앱 아이콘을 다시 만든다
python tools/embed-logo.py
python tools/make-icon.py            # Electron 방식을 쓸 때만

# 3) 엔진 서식 5종 재빌드  (config 가 바뀌었으므로)
python tools/prep-bg.py birth 서식원본/출생신고서.pdf    # engine/assets/*.b64 가 없을 때만
node tools/build-form.js birth
node tools/build-form.js death ; node tools/build-form.js naming
node tools/build-form.js cert  ; node tools/build-form.js realestate

# 4) 배포 3곳 동기화
bash tools/sync-kiosk.sh

# 5) 인쇄물 확인 → 기준선을 그 기관 기준으로 갱신
python tools/verify-print.py            # 작성예시 주소가 바뀌었으니 차이가 나는 것이 정상
python tools/verify-print.py --update   #   눈으로 확인한 뒤 갱신
```

그리고 **손으로** 마무리할 것:

- **작성예시 주소** — `rebrand.py` 는 시 이름만 바꿉니다. `산본로`·`금정동` 같은 군포 도로명·법정동이
  남아 있으면 그 기관 지역 주소로 고치십시오(실행 결과에 남은 자리를 목록으로 알려 줍니다).
  작성예시는 시민이 "이렇게 쓰면 되는구나"를 보는 화면이라 그 지역 주소여야 자연스럽습니다.
- **운영문서** `운영문서/*.md` 의 부서명·담당자·연락처·기안 날짜 → 고친 뒤
  `python tools/make-manual.py` 로 PDF를 다시 만듭니다(**날짜는 `2026.08.04` 처럼 점으로**.
  하이픈으로 쓰면 DLP가 개인정보로 오인해 문서를 암호화하는 환경이 있습니다).
- **서식 원본** — 리포에 `서식원본/`이 없다면 [국가법령정보센터](https://law.go.kr)·정부24에서
  해당 별지서식을 받아 두십시오. `prep-bg.py` 의 입력으로만 쓰이고 앱 실행에는 필요 없습니다.
- **여권 도우미의 창구 표기** — `officeName`·`windowName`(예: "민원여권과", "여권 접수창구")이
  기관마다 다릅니다. `passport-helper-v1.html` 상단 `ORG_CONFIG` 에서 확인하십시오.

### 확산 체크리스트

- [ ] `rebrand.py` 실행, 남은 `군포` 0건 확인 — `grep -rn 군포 index.html *-helper-v1.html forms/ 운영문서/`
- [ ] 로고 교체 + `embed-logo.py` 재실행 (화면 전용이며 인쇄물에는 로고가 나오지 않습니다)
- [ ] 엔진 5종 재빌드 → `sync-kiosk.sh --check` 통과
- [ ] `verify-print.py` 로 인쇄물 확인 → 기준선 갱신
- [ ] 작성예시 주소를 그 지역 주소로 교체
- [ ] 운영문서 부서·담당자·연락처 기입 후 PDF 재생성
- [ ] 키오스크 PC에서 `관리자_개인정보보호_설정.bat` 1회 실행, 프린터 배율 100%·여백 0
- [ ] 실제 인쇄물 1장을 창구에서 접수 가능한지 확인(판독·기재란 위치)

## C. 서식을 추가한다

`engine/README.md` 의 「새 서식 만들기」를 따르면 **config 파일 하나**로 새 서식이 생깁니다
(공통 로직은 손대지 않습니다). 좌표는 PDF에서 뽑습니다 — `get_text('words')`(라벨·괄호),
`get_drawings()`(격자선), 체크박스는 `rawdict` 글리프 중심. 그 뒤 헤드리스 크롬으로 인쇄해
정합을 눈으로 확인하는 순서입니다.

먼저 **`CLAUDE.md` 와 `docs/GOTCHAS.md` 를 읽으십시오.** 조용히 실패하는 함정이 정리돼 있습니다
(선택 표기가 서식마다 `○`/`✔`로 다르다, 값은 라벨 줄이 아니라 단위 글리프 줄에 놓인다 등).

새로 만든 서식을 다시 공유해 주시면 다른 기관이 그대로 씁니다. 서식 하나가 늘 때마다
전국이 같은 품질로 올라가는 구조입니다.

## 유지보수를 AI에게 맡길 때

이 리포는 그것을 전제로 정리돼 있습니다. 처음 붙일 때 이렇게 지시하십시오.

> `CLAUDE.md` 와 `docs/GOTCHAS.md` 를 먼저 읽어라. 무엇이 원본이고 무엇이 생성물인지 그 표를 따르라.
> 서식·좌표·엔진·CSS를 고쳤으면 반드시 `python tools/verify-print.py` 로 인쇄물이 그대로임을
> 보이고(0px), `bash tools/sync-kiosk.sh --check` 를 통과시켜라. 인쇄물이 달라졌다면 왜인지 설명하고
> 승인받은 뒤에만 `--update` 로 기준선을 갱신하라. 엔진 서식 5종의 루트 HTML은 직접 고치지 마라.

핵심은 **`verify-print.py`가 회귀를 잡아 준다**는 점입니다. 좌표가 1pt만 밀려도 픽셀 수로 드러나므로,
사람이 인쇄물을 눈으로 다시 검사하지 않아도 됩니다.
