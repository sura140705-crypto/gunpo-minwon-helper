## Ⅰ. 이 문서에 대하여

- 이 문서는 **창구 직원·안내 담당자용 상세 매뉴얼**입니다. 화면의 각 부분이 무엇인지, 서식마다 어떤 항목을 묻고 어디서 시민이 자주 막히는지를 자세히 담았습니다.
- 시민에게 나눠 주는 **한 장 요약본은 〔붙임 2〕 사용 매뉴얼**입니다. 두 문서의 내용은 같고, 이 문서가 더 자세합니다.

- 이 문서는 **키오스크 전용 프로그램(설치 파일 `.exe`)** 을 기준으로 씌어 있습니다. 운영 방식은 이것 하나입니다(2026.08 보안성 검토로 크롬으로 여는 방식은 폐지).

## Ⅱ. 시작하기

### 구동 방식과 여는 방법

이 도우미는 **서버·로그인·회원가입이 없고, 인터넷 연결도 필요하지 않습니다.** 민원실 키오스크에서는 **전용 프로그램(키오스크 버전)** 으로 구동합니다.

| 이용 환경 | 여는 방법 | 비고 |
|---|---|---|
| 민원실 키오스크 | 전원을 켜면 **전용 프로그램**이 첫 화면을 자동으로 엽니다 | 전체화면. 종료·복구는 〔붙임 3〕 참조 |
| 민원실 PC | 바탕화면의 **「군포민원서식도우미」** 바로가기를 두 번 누릅니다 | 전용 프로그램을 설치한 경우 |

> **전용 프로그램(키오스크 버전)이 정식 운영 기준입니다.** 화면·작성 방법은 어느 방식이든 같고, **인쇄 과정만 다릅니다**(Ⅳ장).

> ### 웹 주소는 테스트용 비공개 사이트입니다
> - 개발·검증·시연 목적의 **비공개 테스트 주소**가 따로 있습니다(담당자 문의).
> - 대외 공개·시민 안내용 정식 서비스 주소가 **아닙니다.** 시민에게 주소를 안내하지 마십시오.
> - 실제 민원실 운영은 위 표와 같이 **키오스크 전용 프로그램**으로 구동합니다.

## Ⅲ. 작성 화면 자세히 보기

### 화면 구성

넓은 화면(키오스크·민원실 PC)은 **실제 서식 미리보기**와 **단계별 안내창(코치)** 이 나란히 놓입니다. 시민이 안내창에 답하면 그 즉시 서식의 해당 칸이 채워집니다.

> ### 서식마다 좌우 배치가 다릅니다
> - **여권발급신청서** : 안내창이 **왼쪽**, 서식이 오른쪽. 상단의 **[↔ 좌우 바꾸기]** 로 위치를 바꿀 수 있습니다.
> - **그 밖의 7종** : 서식이 **왼쪽**, 안내창이 오른쪽. 좌우 바꾸기 버튼은 없습니다.
>
> 시민이 “화면이 설명과 다르다”고 하면 어느 서식인지 먼저 확인해 주세요.

### 상단 버튼

![[그림 2] 상단 버튼 — 어느 서식에서나 같은 자리에 있습니다.](fig:topbar)

| 버튼 | 하는 일 | 창구 안내 시 |
|---|---|---|
| ← 서식 목록 | 첫 화면(허브)으로 돌아갑니다 | 입력 내용은 사라집니다 |
| 작성예시 (2종) | 예시 데이터를 자동으로 채웁니다 | **설명용**. 실제 신청 전 반드시 [초기화] |
| 초기화 | 입력 내용을 모두 지웁니다 | 확인 창이 한 번 뜹니다 |
| 미리보기 | 완성된 서식을 크게 봅니다 | 인쇄 전 확인용 |
| 🖨️ 인쇄 | 안내 창을 거쳐 인쇄합니다 | 키오스크는 **바로 출력**됩니다(Ⅳ장) |
| ↔ 좌우 바꾸기 | 서식·안내창 위치를 바꿉니다 | **여권 도우미에만 있습니다** |

### 안내창(코치)의 각 부분

![[그림 3] 안내창 구성 — 제목, 진행 표시, 질문, 쉬운 말 풀이, 유의사항, 입력칸, 이동 버튼.](fig:coach)

1. **단계 제목과 진행 표시** — 지금 몇 단계인지(예: 7 / 11 단계)와 동그라미로 된 진행 막대. **지나온 단계의 동그라미를 누르면 그 단계로 되돌아갑니다.**
2. **큰 질문** — 이 단계에서 무엇을 물어보는지 한 문장으로.
3. **쉬운 말 풀이(💡 파란 상자)** — 어려운 용어나 판단 기준을 풀어 설명합니다.
4. **유의사항(⚠️ 노란 상자)** — 틀리면 접수가 안 되는 항목을 경고합니다. 예: 부동산 신고서의 “소재지는 지번주소로”.
5. **입력칸** — 이름표 옆에 **필수**(빨강) 또는 **선택**(회색) 배지가 붙습니다. 이름표 아래 작은 글씨는 그 칸의 도움말입니다.
6. **[← 이전] [다음 →]** — 단계 이동. 마지막 단계에서는 [다음]이 **[인쇄하기 🖨️]** 로 바뀝니다.
7. **[이 단계는 잘 모르겠어요 · 나중에 창구에서]** — 건너뛰기. 건너뛴 단계는 마지막 확인 화면에 **🤔 표시**로 모여 보입니다.

### 필수 항목을 비우면 넘어가지 않습니다

![[그림 4] 필수 항목을 비운 채 [다음]을 누르면 빨간 글씨로 어떤 칸이 비었는지 알려 줍니다.](fig:required)

- 빨간 안내에 적힌 칸을 채우면 바로 다음 단계로 넘어갑니다.
- 정말 모르는 항목이면 **[잘 모르겠어요]** 로 건너뛰고 창구에서 확인하도록 안내해 주세요.

### 미리보기

![[그림 5] [미리보기] — 완성된 서식을 화면 전체로 크게 확인합니다. 첨부 서식이 함께 생기는 경우 여러 장이 이어서 보입니다.](fig:preview)

- 여권 도우미는 미성년자면 **법정대리인 동의서**, 성인 대리 신청이면 **위임장**이 함께 만들어져 미리보기에도 이어서 나옵니다.
- 좁은 화면(스마트폰)에서는 서식이 숨겨져 있으므로, **[🔍 완성된 서식 미리보기]** 버튼으로 확인합니다.

### 마지막 단계 — 작성 내용 확인

![[그림 6] 확인 화면 — 입력한 내용을 항목별로 모아 보여 줍니다. 비어 있는 칸은 ‘(비어 있음)’으로 표시됩니다.](fig:summary)

- **🤔 표시**가 붙은 항목이 창구에서 확인해야 할 항목입니다.

## Ⅳ. 인쇄와 제출

> ### ⚠️ 인쇄 창은 뜨지 않습니다
> 인쇄 창이 **뜨지 않고, 관리자가 지정해 둔 프린터로 바로 출력**됩니다.
> 여백 ‘없음’·배율 ‘100%’·배경 인쇄는 **프로그램이 이미 고정**해 두었으므로 시민이 맞출 것이 없습니다.
>
> 이 값이 어긋나면 인쇄물의 칸 위치·크기가 달라집니다. 특히 **여권발급신청서는 기계 판독을 하므로 오류가 발생**하는데,
> 프로그램이 고정하므로 그런 일이 생기지 않습니다.

- **[🖨️ 인쇄]** 를 누르면 **안내 창이 먼저 뜹니다.** 내용을 확인한 뒤 오른쪽 아래 파란 단추를 누르면 인쇄가 진행됩니다.
  - 안내 창에는 **개인정보 안내**(출력물 직접 수령·관리, 공용 PC 사용 후 창 닫기, 인쇄 후 화면 초기화)가 **붉은 글씨로 강조**되어 함께 표시됩니다.
  - **[취소]** 를 누르면 인쇄하지 않고 작성 화면으로 돌아갑니다(화면은 초기화되지 않습니다).

![[그림 8] 인쇄 직전 안내 창 — 여백·배율과 개인정보 안내를 붉은 글씨로 강조합니다. 화면 크기에 맞춰 조판되어 스크롤 없이 한눈에 보입니다.](fig:notice)

> **안내 창 문구에 대하여** — 단추 이름이 **[인쇄 창 열기]** 이고 안내 창에 여백·배율 항목이 남아 있으나, 이는 예전 문구입니다. **인쇄 창은 뜨지 않고 바로 출력**되며 여백·배율은 프로그램이 고정합니다. 시민이 “인쇄 창이 안 떴는데 종이가 나왔다”고 하면 **정상 동작**입니다.

- 키보드 `Ctrl+P` 는 **차단**되어 있습니다. 화면의 [🖨️ 인쇄] 버튼을 쓰도록 안내해 주세요.
- **인쇄가 끝나면 화면이 첫 화면으로 초기화됩니다**(Ⅴ장). 종이가 제대로 나왔는지 먼저 확인해 주세요.
- **인쇄되지 않는 경우에는 사유가 화면에 표시됩니다**(프린터 준비 안 됨 등). 6초 뒤 첫 화면으로 돌아가므로, 종이가 나오지 않았다면 프린터를 확인한 뒤 **처음부터 다시 작성**해야 합니다.

### 인쇄한 뒤 해야 할 일

- **노란 형광으로 표시된 칸**이 인쇄 후 직접 써야 하는 자리입니다. 대부분 **서명 또는 날인** 칸입니다.
  - 예: 부동산거래계약 신고서는 오른쪽 **「(서명 또는 인)」** 칸 세 곳(매도인·매수인·개업공인중개사)에 형광이 표시됩니다.
- 신분증, 서식별 첨부서류(Ⅵ장 참조)를 함께 준비해 창구에 제출합니다.

### 인쇄 관련 흔한 문의

| 증상 | 원인 | 조치 |
|---|---|---|
| 인쇄 창이 안 뜨고 바로 출력된다 | **정상 동작** | 안내 불필요(설정이 이미 고정되어 있습니다) |
| 눌렀는데 종이가 안 나온다 | 프린터 전원·용지·연결, 일시중지, 프린터 미지정 | **화면에 사유가 표시됩니다.** 프린터를 확인하고 다시 작성(직원 : 〔붙임 3〕 제Ⅳ·Ⅴ항) |
| “프린터가 지정되지 않았습니다” | 설치 시 프린터 지정을 안 한 것 | 직원 : 〔붙임 3〕 제Ⅴ항으로 지정 |
| 칸 위치·크기가 실제 서식과 다르다 | 프린터 쪽 용지·축소 설정 | 여백·배율은 프로그램이 고정하므로 **프린터 설정**(A4, 자체 축소 끄기)을 확인 |
| 형광색이 인쇄되지 않는다 | 프린터 드라이버 설정 | 드라이버의 **배경 인쇄·컬러 설정** 확인(프로그램은 배경 인쇄를 켜서 보냅니다) |
| `Ctrl+P` 가 안 먹는다 | **정상 동작**(차단됨) | 화면의 [🖨️ 인쇄] 버튼 사용 |
| 인쇄 후 입력 내용이 사라졌다 | 개인정보 보호를 위한 **인쇄 후 자동 초기화** | 정상 동작(Ⅴ장). 다시 인쇄해야 하면 처음부터 작성 |

## Ⅴ. 개인정보 보호

- 입력한 내용은 **저장되지도, 서버로 전송되지도 않습니다.** 화면을 닫거나 새로고침하면 즉시 사라집니다.
- 서식 이미지·글꼴·기능이 모두 프로그램 안에 들어 있어 **외부 통신이 전혀 없습니다.** 이 키오스크는 **인터넷에 연결되어 있지 않습니다.**
- 민원실 키오스크는 **인쇄만 가능하고 파일(PDF)로 저장할 수 없습니다.** 전용 프로그램은 **인쇄 창 자체를 열지 않아** ‘PDF로 저장’을 고를 경로가 없으며, 파일로 저장하는 가상 프린터도 제거해 둡니다(설정 절차는 〔붙임 3〕 제Ⅵ항).

| **화면이 다른 프로그램에 가려지면** | **즉시** 첫 화면으로 | 뒷사람이 앞사람 내용을 보지 못하게 하는 장치입니다 |
| **프로그램을 껐다 켜면** | 흔적 없이 처음부터 | 시작·종료할 때 임시 자료를 비웁니다 |

> 시민이 “쓰던 게 갑자기 사라졌다”고 하면 위 네 가지 중 하나입니다. **고장이 아닙니다.**
> 다만 **다시 작성해야 하므로**, 작성 중에는 자리를 비우지 않도록 미리 안내해 주세요.

키오스크 PC는 이와 별개로 **재부팅할 때 저장 내용이 기준 상태로 되돌아가도록** 되어 있어(〔붙임 3〕 제Ⅺ항),
개점 전 재부팅만으로 전날 흔적이 남지 않습니다.

### 인쇄가 끝나면 바로 초기화

인쇄가 끝나면 **곧바로 화면을 가리고**, 출력물을 챙겨 가라는 안내를 **약 5초간** 보여준 뒤 **첫 화면으로 돌아갑니다.** 뒷사람이 앞사람의 신청 내용을 보는 것도 개인정보 유출이기 때문입니다.

![[그림 9] 인쇄 직후 안내 — 화면을 가리고 첫 화면으로 돌아갑니다. 출력물을 챙겨 가라는 안내가 함께 표시됩니다.](fig:printed)

- **출력물을 꼭 챙겨 가도록** 안내해 주세요. 출력물에는 개인정보가 들어 있습니다.
- **인쇄에 실패하거나 취소한 경우에도 초기화됩니다.** 성공·실패를 구분해 화면을 남겨 두면 개인정보가 더 오래 노출되기 때문입니다. 인쇄 직전 안내 창에 이 내용이 미리 표시됩니다.
- 인쇄가 제대로 되지 않았다면 **다시 작성**해야 합니다. 창구에서 도와주십시오.

### 3분 무동작 시 자동 초기화

![[그림 10] 3분 동안 아무 동작이 없으면 마지막 30초 경고 후 첫 화면으로 돌아가며 입력 내용이 지워집니다.](fig:idle)

- 경고가 떴을 때 화면을 터치하거나 **[계속 작성하기]** 를 누르면 계속 작성할 수 있습니다.
- 키오스크·공용 PC에서 시민이 자리를 비웠을 때 개인정보가 남지 않도록 하는 장치입니다.

### 창구 응대 시 주의

- 시민의 주민등록번호·주소를 **직원이 대신 입력하지 않도록** 합니다. 화면을 보며 안내만 하고, 입력은 본인이 하게 하십시오.
- **출력물은 도우미가 직접 건네주는 것을 원칙**으로 합니다. 프린터에 방치되지 않게 하는 가장 확실한 방법입니다.
- 잘못 인쇄된 종이는 그 자리에서 파기하도록 안내합니다.
- **인쇄 대기열에 남은 작업은 개인정보입니다.** 개점 전 점검에서 발견하면 즉시 삭제하십시오(〔붙임 4〕).

### 직원이 알아 두어야 할 잠금 동작

이 키오스크는 시민이 프로그램 밖으로 나갈 수 없도록 잠겨 있습니다. **정상 동작이므로 고장으로 신고하지 마십시오.**

| 동작 | 결과 |
|---|---|
| `Ctrl` + `P` (인쇄 단축키) | **눌리지 않습니다.** 화면의 [🖨️ 인쇄] 버튼을 쓰십시오 |
| `F12`·개발자도구 단축키 | 차단 |
| `Alt` + `F4` | **종료되지 않습니다.** 관리자 PIN 확인을 거칩니다 |
| 프로그램을 두 번 실행 | 열리지 않고 원래 창이 앞으로 나옵니다 |
| `Ctrl` + `Shift` + `Q` | 종료 — **관리자 PIN 입력 창**이 뜹니다 |
| `Ctrl` + `Shift` + `H` | 첫 화면으로 복귀 (PIN 불필요) |

> 종료 PIN 은 **직원만 알고 있어야** 하며, 화면·주변에 적어 두지 마십시오.
> PIN 을 잊었으면 〔붙임 3〕 제Ⅴ항으로 다시 설정합니다.

- **신고 기한** : **계약 체결일부터 30일 이내.** 기한을 넘기거나 거짓으로 신고하면 과태료가 부과됩니다. 소유권이전등기는 별도로 **60일 이내**에 신청해야 합니다.

> ### ⚠️ 이 서식에서 특히 자주 틀리는 세 가지
> 1. **⑥ 소재지는 지번주소로** — 도로명주소(○○로 00)로 적으면 접수되지 않습니다. 등기사항증명서·토지대장의 **지번**(○○동 000-0)으로, 아파트는 **동·호수까지** 적습니다. ①② 주소란(주민등록 주소)은 도로명이어도 됩니다.
> 2. **토지면적은 단지 전체 면적** — 내 지분이 아니라 그 아파트 토지(단지 대지)의 **전체 면적**입니다. 내 몫은 **대지권비율**(예: 45000분의 52.43)로 나타냅니다. 실제 거래한 면적은 ⑦ 계약대상 면적에 적습니다.
> 3. **개업공인중개사 전화번호는 사무실 번호** — 반드시 적어야 하며 휴대전화번호로 대신할 수 없습니다.

- **거래가격 입력** — 가장 중요한 항목입니다.

#### 별지 — 당사자·부동산이 여럿일 때

신고서에는 매도인·매수인이 각 한 명, 부동산이 한 건만 들어갑니다. 그보다 많으면 **별지**에 이어서 적습니다(시행규칙 별지 제1호서식 작성방법 11). 정해진 서식이 아니라 별지 샘플 서식을 따르는 자유 양식입니다.

- **별지 단계**에서 아래 다섯 가지를 각각 **[＋ 추가]** 로 늘립니다(구역마다 최대 4개).

| 추가 구역 | 쓰는 경우 | 적는 것 |
|---|---|---|
| 매도인 추가 | 공동명의 매도, 공동상속 | 성명·주민등록번호·주소·거래지분·전화 |
| 매수인 추가 | **부부 공동명의 매수**(가장 흔함) | (같음) |
| 개업공인중개사 추가 | 공동중개(매도·매수 중개사가 다를 때) | 성명·주민등록번호·상호·등록번호·사무소 소재지·전화 |
| 소재지 관계지번 추가 | 한 부동산이 여러 필지에 걸칠 때 | 관계지번·지목·토지면적·거래지분·대지권비율 |
| 거래부동산 추가 | 한 번에 둘 이상 거래 | 소재지·종류·계약종류·면적·물건별 거래가격 |

- 하나라도 추가하면 **별지가 서식 다음 장에 자동으로 만들어져** 함께 인쇄됩니다. 추가한 만큼 표의 줄이 늘고, 한 장을 넘치면 다음 장으로 이어집니다.
- 별지 머리에 신고서의 매도인·매수인·소재지가 함께 인쇄되어 **어느 신고서의 별지인지** 알 수 있습니다.
- **인쇄 후 신고서와 별지 사이에 간인**하여 함께 제출합니다.
- 거래지분은 **매도인 쪽 합계와 매수인 쪽 합계가 일치**해야 합니다(예: 매도인 단독, 매수인 2명 각 2분의 1).

## Ⅶ. 창구 직원용 안내

### 역할

- 이 도우미는 **작성을 돕는 도구**이며, **최종 접수·심사는 창구에서** 진행합니다. 화면에 표시된 안내는 참고용이므로, 법령 해석이 필요한 사항은 담당자가 판단합니다.

### 고령층·처음 이용자 응대 순서

1. 첫 화면에서 **어떤 서식인지 함께 확인**하고 카드를 눌러 줍니다.
2. **[작성예시]** 로 완성된 모습을 한 번 보여 줍니다. “이렇게 채워집니다”가 가장 빠른 설명입니다.
3. **[초기화]** 를 누르고 본인 정보를 입력하게 합니다. (입력은 본인이 하도록)
4. 어려운 용어가 나오면 **💡 쉬운 말 풀이**를 함께 읽습니다.
5. 마지막 확인 화면에서 **🤔 표시 항목만** 같이 확인·보완합니다.
6. 인쇄를 누르면 **키오스크에서는 바로 출력**됩니다(인쇄 창이 뜨지 않습니다). 종이가 나왔는지 함께 확인하고, **출력물을 챙겨 가도록** 안내합니다.
   - 종이가 나오지 않으면 **화면에 사유가 표시**되므로, 그 문구를 보고 프린터를 조치합니다.

### 자주 받는 요청 처리

| 시민 요청 | 처리 |
|---|---|
| “처음부터 다시 하고 싶어요” | [초기화] |
| “앞 단계를 고치고 싶어요” | 진행 막대의 지나온 동그라미를 누름 |
| “이 항목은 모르겠어요” | [잘 모르겠어요]로 건너뛰고 창구에서 확인 |
| “집에서 미리 쓸 수 있나요” | 현재는 민원실 키오스크·PC에서만 이용 가능(시범운영). 웹 주소는 안내하지 않음 |
| “종이 서식으로 받을 수 있나요” | 기존 종이 서식과 병행 운영. 도우미는 선택 사항 |

## Ⅷ. 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 화면이 처음 화면으로 돌아갔다 | 3분 무동작 자동 초기화 | 정상 동작. 경고가 뜨면 [계속 작성하기] |
| [다음]이 눌리지 않는다 | 필수 항목 미입력 | 빨간 안내에 적힌 칸을 채움 |
| 입력했는데 서식에 안 보인다 | 해당 없는 조건부 칸 | 그 항목을 쓰는 조건(외국인·입주권 등)을 켰는지 확인 |
| 서식이 화면에 없다 | 좁은 화면(스마트폰) | [🔍 완성된 서식 미리보기] 사용 |
| 설명과 좌우가 반대다 | 서식마다 배치가 다름 | 여권만 안내창이 왼쪽(Ⅲ장) |
| 인쇄물이 실제 서식과 다르다 | 프린터 쪽 용지·축소 설정 | 여백·배율은 프로그램이 고정 (Ⅳ장) |
| 눌렀는데 종이가 안 나온다 | 프린터 전원·용지·일시중지, 프린터 미지정 | 화면의 사유 확인 후 다시 작성. 직원은 〔붙임 3〕 제Ⅳ·Ⅴ항 |
| 인쇄가 2장 이상 나온다(부동산) | 별지가 함께 인쇄됨 | 정상. 당사자·부동산을 추가했을 때 생깁니다 |
| 화면이 열리지 않는다(키오스크) | 프로그램·바로가기 문제 | 〔붙임 3〕 키오스크 설치·운영 안내 참조 |
| 화면을 벗어나고 싶다(직원) | 키오스크 잠금 상태 | `Ctrl`+`Shift`+`Q` 종료(**관리자 PIN 필요**) · `Ctrl`+`Shift`+`H` 첫 화면(〔붙임 3〕) |
