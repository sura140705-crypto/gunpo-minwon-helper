# 「군포시 민원 서식 작성 도우미」 키오스크 설치·운영 안내

〔붙임 3〕 · 작성일 2026. 8. 7. · 담당 민원봉사과 031-390-0131

> 운영 방식은 **키오스크 전용 프로그램(설치 파일 `.exe`)** 하나입니다.
> 인터넷 없이 키오스크 PC 자체에서 완전히 동작하며, 외부 서버·데이터베이스가 필요 없습니다.
> 서식 8종과 서식 이미지·글꼴이 **프로그램 안에 모두 들어 있어** 별도 파일을 함께 복사하지 않아도 됩니다.
>
> ※ 2026.08 보안성 검토 결과를 반영해 **브라우저(크롬)로 여는 방식은 폐지**했습니다.
> 그 방식은 인쇄 대화상자가 열려 시민이 가상 프린터(‘PDF로 저장’·`Hancom PDF`)를 고를 수 있고,
> 인쇄할 프린터를 프로그램이 고정할 수 없어 요구 수준을 맞출 수 없었습니다.

## Ⅰ. 배포 파일

| 파일 | 크기 | 용도 |
|------|------|------|
| `군포민원서식도우미-1.0.0-x64.exe` | 약 80MB | **설치본 — 정식 운영용.** 키오스크에 설치해 상시 사용 |
| `군포민원서식도우미-portable-1.0.0.exe` | 약 80MB | 설치 없이 실행하는 판. 시연·임시 PC용 |
| `관리자_개인정보보호_설정.bat` + `kiosk-privacy.ps1` | 약 21KB | **설치 시 필수** — 프린터 지정·가상 프린터 제거·종료 PIN 설정(제Ⅴ·Ⅵ항). 두 파일은 **같은 폴더**에 두어야 동작 |

> **관리자 스크립트는 설치본 안에도 함께 들어갑니다.** 설치한 PC에서는 아래 폴더에 그대로 있으므로,
> 배포 파일을 따로 챙기지 않았어도 실행할 수 있습니다.
>
> ```
> <설치 폴더>\resources\admin\관리자_개인정보보호_설정.bat
> ```
>
> 설치 폴더는 바탕화면 바로가기를 **마우스 오른쪽 → [파일 위치 열기]** 로 찾을 수 있습니다.

- 설치본과 포터블은 **기능이 같습니다.** 상시 운영은 설치본을 쓰십시오.
  포터블은 실행할 때마다 프로그램을 임시 폴더에 풀었다가 종료 시 지우므로 **시작이 느리고**, 매번 같은 과정을 반복합니다.
- 프로그램 버전은 파일 이름의 `1.0.0` 으로 구분합니다. 배포 시 이 이름을 바꾸지 마십시오.

## Ⅱ. 설치 〔순서를 반드시 지킬 것〕

이 키오스크는 **재부팅하면 디스크가 기준 상태로 복원되는 PC(PC보안관 등 복원 솔루션)** 에 설치합니다.
그래서 **설정을 마친 뒤에 기준 이미지를 저장**해야 합니다. 순서를 지키지 않으면 아래 문제가 생깁니다.

> ### ⚠️ 순서를 틀리면 매일 아침 인쇄가 되지 않습니다
> 프로그램은 프린터 지정과 종료 PIN 을 `C:\ProgramData\군포민원서식도우미\kiosk.json` 에서 읽습니다.
> 이 경로가 **복원 대상에 들어간 상태에서 기준 이미지를 먼저 저장**하면, 재부팅할 때마다 설정이 사라집니다.
> 그러면 프로그램은 “프린터가 지정되지 않았습니다”를 띄우고 **인쇄를 하지 않습니다**(개인정보 보호를 위한
> 의도된 동작입니다. 제Ⅳ항 참조). **설정 → 확인 → 기준 이미지 저장** 순서를 지키십시오.

### 설치 순서

| 순서 | 작업 | 비고 |
|---|---|---|
| 1 | 윈도우 설치 · **프린터 드라이버 설치** | 이 PC는 **본 프로그램 전용**입니다. 문서 편집기(한글·오피스) 등은 설치하지 않습니다 |
| 2 | `군포민원서식도우미-1.0.0-x64.exe` 설치 | 설치는 **로그인한 계정 기준**. 키오스크용 계정에서 설치할 것 |
| 3 | `관리자_개인정보보호_설정.bat /status` | 실물 프린터 이름 확인 (변경 없음) |
| 4 | `관리자_개인정보보호_설정.bat /only "프린터이름"` | 프린터 지정 + 가상 프린터 제거 (제Ⅴ·Ⅵ항) |
| 5 | `관리자_개인정보보호_설정.bat /pin` | 관리자 종료 PIN 설정 (제Ⅴ항) |
| 6 | 전용 계정 · **셸 교체** · USB·BIOS 정책 적용 | 제Ⅺ항. 정보통신과 협조 |
| 7 | `군포민원서식도우미.exe --selfcheck` | **전 항목 `[양호]` 확인** (제Ⅵ항) |
| 8 | ★ **이 상태를 기준 이미지로 저장하고 복원 보호를 활성화** | 순서상 반드시 마지막 |
| 9 | 재부팅 후 `--selfcheck` 재실행 | 설정이 유지되는지 **반드시 확인** |

- 9번에서 “지정 프린터 : 미지정”이 나오면 설정이 복원 대상에 들어간 것입니다.
  **복원 제외(예외) 폴더**로 `C:\ProgramData\군포민원서식도우미\` 를 지정할 수 있으면 지정하고,
  지정할 수 없으면 3~5번을 다시 수행한 뒤 **기준 이미지를 다시 저장**하십시오.
- 바탕화면 바로가기는 셸 교체 후에는 쓰이지 않습니다(제Ⅺ항).

### 백신·SmartScreen 경고가 뜰 때

- 이 프로그램에는 **상용 코드 서명 인증서가 없어**, 처음 실행할 때 “Windows의 PC 보호” 경고가 뜰 수 있습니다.
- **[추가 정보] → [실행]** 을 누르면 진행됩니다. 파일 이름·크기가 위 표와 같은지 확인한 뒤 진행하십시오.
- 시청 백신이 차단하는 경우 정보통신과에 예외 등록을 요청합니다.

### 포터블 판을 쓸 때

- 폴더 아무 곳에나 복사해 두고 두 번 누르면 실행됩니다. 설치·삭제 절차가 없습니다.
- 종료하면 임시로 풀렸던 파일이 지워집니다. **입력 내용은 어느 판에서도 저장되지 않습니다.**

## Ⅲ. 실행과 관리자 조작

- 바탕화면의 **「군포민원서식도우미」** 를 두 번 누르면 **전체화면(키오스크 잠금)** 으로 첫 화면이 열립니다.
  - 주소창·메뉴·창 조작 단추가 없어 시민이 다른 프로그램이나 인터넷으로 나갈 수 없습니다.
  - 화면 안의 링크가 새 창을 열려고 해도 **차단**됩니다.
  - **중복 실행되지 않습니다.** 이미 떠 있는 상태에서 다시 실행하면 원래 창이 앞으로 나옵니다.
  - 개발자도구(F12·Ctrl+Shift+I)와 인쇄 대화상자(Ctrl+P)는 **차단**되어 있습니다.

### 관리자 단축키

| 단축키 | 동작 | 쓰는 때 |
|---|---|---|
| `Ctrl` + `Shift` + `Q` | **프로그램 종료** — **관리자 PIN 을 물어봅니다** | 업무 종료, 점검 |
| `Ctrl` + `Shift` + `H` | **첫 화면으로 복귀** | 앞사람 내용이 남아 있을 때, 화면이 멈춘 듯할 때 |

> 이 두 단축키는 **직원만 알고 있도록** 하십시오. 키오스크 화면에 안내하지 마십시오.

- **`Alt` + `F4` 로는 종료되지 않습니다.** 창 닫기도 PIN 확인을 거칩니다.
- ⚠️ **PIN 을 설정하지 않으면 `Ctrl`+`Shift`+`Q` 로 그냥 종료됩니다.** 설치 시 제Ⅴ항에서 반드시 설정하십시오.
  (PIN 미설정 상태에서 종료까지 막으면, 잠긴 키오스크를 열 방법이 없어지기 때문에 일부러 이렇게 두었습니다.)

### 자동 시작(권장) — PC를 켜면 바로 열리게

1. 바탕화면의 **「군포민원서식도우미」** 바로가기를 마우스 오른쪽 → [복사].
2. `Win` + `R` → `shell:startup` 입력 → 열린 폴더에 **붙여넣기**.
3. 다음 부팅부터 첫 화면이 자동으로 열립니다.

## Ⅳ. 인쇄 동작 〔이 방식의 핵심 차이〕

전용 프로그램은 **인쇄 대화상자를 열지 않습니다.** 시민이 [🖨️ 인쇄]를 누르면 안내 창이 뜨고,
확인을 누르는 즉시 **설정에 지정된 프린터로 곧바로 출력**됩니다.

| 항목 | 값 | 설정 주체 |
|---|---|---|
| 여백 | 없음 | **프로그램이 고정** |
| 배율 | 100%(실제 크기) | **프로그램이 고정** |
| 배경 그래픽(서식 이미지·형광 표시) | 인쇄함 | **프로그램이 고정** |
| 매수 | 1매 | **프로그램이 고정** |
| 출력 장치 | **설정 파일에 지정된 프린터** | ← **직원이 지정**(제Ⅴ항) |

- 즉 **여백·배율을 시민이 잘못 만질 여지가 없습니다.**
- 출력 장치도 **기본 프린터를 따라가지 않고** 설정 파일에 적힌 프린터를 씁니다.
  기본 프린터가 어느 날 바뀌어도 엉뚱한 곳으로 나가지 않습니다.
- 인쇄 대화상자를 여는 단축키(`Ctrl`+`P`)도 **차단**되어 있습니다.

### 인쇄하지 않는 경우 〔안전 우선〕

다음 중 하나라도 해당하면 프로그램은 **인쇄하지 않고 안내 화면을 띄웁니다.**
개인정보가 파일로 남거나 대기열에 쌓이는 것보다, 인쇄를 안 하는 편이 안전하기 때문입니다.

| 상황 | 화면 | 조치 |
|---|---|---|
| 프린터가 지정돼 있지 않다 | “프린터가 지정되지 않았습니다” | 제Ⅴ항으로 지정 |
| 지정한 프린터가 없어졌다 | “지정된 프린터를 찾을 수 없습니다” | 이름 확인 후 다시 지정 |
| 지정한 것이 가상 프린터다 | “파일로 저장하는 프린터는 사용할 수 없습니다” | 실물 프린터로 다시 지정 |
| 프린터가 일시중지·오프라인·용지 없음 | “프린터가 준비되지 않았습니다 : (사유)” | 프린터를 조치한 뒤 다시 작성 |
| 인쇄 보호 기능이 적용되지 않았다 | “지금은 이용할 수 없습니다” | 종료 후 점검(제Ⅵ항 적용 확인) |

### 인쇄 작업이 대기열에 남지 않게 합니다

- 프린터를 일시중지해 두면 인쇄 작업이 대기열에 쌓이는데, 그 안에는 **개인정보가 그대로 들어 있습니다.**
- 프로그램은 ① 인쇄 전 프린터 상태를 확인해 **멈춰 있으면 아예 보내지 않고**,
  ② 인쇄 후 **1분이 지나도 남아 있는 작업은 회수(삭제)** 하며, ③ 시작·종료 시에도 잔여 작업을 정리합니다.
- 프린터 속성의 **[인쇄된 문서 유지]** 가 켜져 있으면 정상 인쇄 후에도 작업이 남습니다.
  제Ⅴ항의 설정 스크립트가 이 값을 꺼 줍니다.

### 〔주의〕 현재 화면 문구와의 차이

- 인쇄 직전 안내 창에는 아직 크롬 방식 기준 문구가 남아 있습니다.
  - 단추 이름이 **[인쇄 창 열기]** 이지만, 전용 프로그램에서는 **인쇄 창이 뜨지 않고 바로 출력**됩니다.
  - 안내 창의 “**2. 인쇄 창에서 이렇게 맞춰 주세요**”(여백·배율) 항목은 전용 프로그램에서는 **해당하지 않습니다**(프로그램이 이미 고정).
- 시민이 “인쇄 창이 안 떴는데 종이가 나왔다”고 하면 **정상 동작**입니다. 창구에서 그렇게 안내해 주십시오.

### 〔주의〕 인쇄에 실패해도 화면은 초기화됩니다

- 개인정보 보호를 위해, **인쇄 성공·실패와 관계없이** 인쇄 시도 후 화면은 첫 화면으로 돌아갑니다.
- 프린터가 꺼져 있거나 용지가 없으면 **종이는 나오지 않은 채 입력 내용만 사라집니다.**
- 그러므로 **개점 전 프린터 점검(제Ⅶ항)** 이 이 방식에서는 특히 중요합니다.

## Ⅴ. 프린터 지정·종료 PIN 〔필수 · 설치 시 1회〕

프로그램은 **설정 파일에 적힌 프린터로만** 인쇄합니다. 그 파일을 만드는 것이 이 단계입니다.

```
설정 파일 : C:\ProgramData\군포민원서식도우미\kiosk.json
```

직접 편집할 필요는 없습니다. 아래 스크립트가 만들어 줍니다.

### 1) 프린터 이름 확인 (권한 불필요, 아무것도 바꾸지 않음)

`Win` + `R` → `cmd` → 파일이 있는 폴더(배포 폴더 또는 `<설치 폴더>\resources\admin\`)로 이동 후

```
관리자_개인정보보호_설정.bat /status
```

설치된 프린터 목록이 나옵니다. 키오스크에서 쓸 **실물 프린터 이름을 그대로 적어 둡니다.**

### 2) 프린터 지정 (관리자 권한)

파일을 **마우스 오른쪽 → [관리자 권한으로 실행]** 하고 아래처럼 실행합니다.

```
관리자_개인정보보호_설정.bat /only "캐논 복합기"
```

따옴표 안은 1)에서 확인한 이름입니다. 이 한 번으로 다음이 함께 처리됩니다.

- 지정한 프린터를 **설정 파일에 기록**(프로그램이 이 프린터로만 인쇄)
- 지정한 프린터를 **기본 프린터로 설정**
- **파일로 저장하는 가상 프린터 제거**(제Ⅵ항)
- 그 프린터의 **[인쇄된 문서 유지] 끄기**(대기열 잔존 방지)

### 3) 관리자 종료 PIN 설정 (관리자 권한)

```
관리자_개인정보보호_설정.bat /pin
```

새 PIN 을 두 번 입력하면 끝입니다(4자 이상). 이 PIN 은 `Ctrl`+`Shift`+`Q` 로 종료할 때 물어봅니다.

> PIN 은 저장되지 않고 **대조용 해시(SHA-256)만** 기록됩니다. 잊어버리면 이 명령으로 다시 설정하십시오.

### 4) 확인

```

## Ⅵ. 파일 저장 차단 〔필수 · 설치 시 1회〕

키오스크는 **인쇄만 하고, 파일로는 저장할 수 없어야** 합니다. 두 겹으로 막습니다.

1. **프로그램** — 인쇄 대화상자를 열지 않으므로 시민이 ‘PDF로 저장’을 **고를 경로 자체가 없고**,
   지정된 프린터가 가상 프린터로 판별되면 **인쇄를 거부**합니다.
2. **PC 설정** — 파일로 저장하는 가상 프린터를 아예 **제거**합니다(제Ⅴ항 2)에서 함께 처리됨).

| 이 스크립트가 하는 일 | 이유 |
|---|---|
| 가상 프린터 제거(`Microsoft Print to PDF`·`Hancom PDF`·`OneNote`·`XPS`·팩스 등) | 실수로 그쪽으로 인쇄되는 사고를 원천 차단 |
| 윈도우 기능(Print to PDF·XPS) 끄기 | 지워도 다시 생기는 것을 방지 |
| `/only` 로 실물 프린터만 남기고 지정·기본 설정 | 제Ⅴ항을 한 번에 처리 |
| `[인쇄된 문서 유지]` 끄기 | 인쇄 후 대기열에 개인정보가 남지 않게 |

> **주의** — ‘Microsoft Print to PDF’ 만 지워서는 부족합니다. 시청 PC에는 한글오피스가 설치된 경우가 많아 **`Hancom PDF` 프린터로도 PDF 저장이 됩니다.** 위 스크립트는 이런 프린터들을 함께 처리합니다.

- 시민이 입력한 정보는 **PC 메모리에서만** 처리되고, 화면을 닫거나 첫 화면으로 돌아가면 **즉시 사라집니다.** (저장·전송 없음)

### 복원 솔루션이 켜져 있을 때의 순서 〔중요〕

디스크 복원(PC보안관 등)이 켜진 상태에서 설치하면, **재부팅과 함께 업데이트가 사라집니다.**
반드시 아래 순서로 하십시오.

```
1. 복원 보호 해제 (관리자)
2. 새 설치본 설치
3. --selfcheck 로 전 항목 [양호] 확인 + 시험 인쇄 1매
4. 기준 이미지 다시 저장
5. 복원 보호 활성화
6. 재부팅 후 --selfcheck 재실행 — 설정이 유지되는지 확인
```

- 3번의 시험 인쇄를 거르지 마십시오. 프로그램의 표시 엔진이 바뀌면 **인쇄물의 칸 위치가 달라질 수 있습니다.**

### 보안 업데이트 주기

- 이 프로그램은 Electron(크로미움 기반)으로 만들어져 있어, **크로미움의 보안 취약점이 그대로 영향**을 줍니다.
- Electron 은 8주마다 새 버전이 나오고 **최신 3개 버전만 지원**됩니다.
- 따라서 **6개월마다 한 번** 지원 여부를 확인하고, 지원이 끝났으면 지원 중인 버전으로 올려 재배포합니다.
- 올린 뒤에는 **반드시 시험 인쇄로 조판(칸 위치·크기)을 확인**하십시오. 크로미움이 바뀌면 인쇄 결과가 달라질 수 있습니다.

## Ⅺ. 운영 환경 통제 〔OS·물리 설정 · 정보통신과 협조〕

프로그램만으로는 막을 수 없는 것들을 **환경으로** 막습니다. 이 PC는 본 프로그램 **전용**이므로,

### 가. 화면 이탈 방지 — 셸 교체

**`Alt`+`Tab` 과 `Windows` 키는 프로그램이 막을 수 없습니다.** 윈도우가 프로그램보다 먼저 처리하기 때문입니다.
프로그램 쪽에서는 **이탈했을 때 개인정보가 남지 않도록** 화면을 첫 화면으로 되돌리는 것까지만 합니다(제Ⅷ항).
이탈 자체는 아래 OS 조치로 차단합니다.

| 조치 | 내용 | 효과 |
|---|---|---|
| **키오스크 전용 계정 + 자동 로그온** | 시민용 계정을 따로 만들고 부팅 시 자동 로그온 | 관리자 환경과 분리 |
| **셸 교체** | 그 계정의 셸(`Winlogon\Shell`)을 탐색기 대신 이 프로그램으로 지정 | 바탕화면·작업표시줄·시작 메뉴가 **존재하지 않아** `Alt`+`Tab` 대상도, `Windows` 키로 열 것도 없음 |
| **정책** | `Windows` 키 조합 끄기(`NoWinKeys`), 작업 관리자 사용 안 함(`DisableTaskMgr`) | 잔여 우회 경로 차단 |

> ⚠️ **셸을 교체하면 그 계정에서는 이 프로그램 외에 아무것도 뜨지 않습니다.**
> 점검·복구용으로 **관리자 계정 로그인 경로를 반드시 남겨 두고**, 종료 PIN(제Ⅴ항)을 **먼저** 설정하십시오.
> Windows 11 **Pro** 에서 가능한 방식이며, ‘할당된 액세스(Assigned Access)’ 기능은 이 프로그램 형태에는 적용되지 않습니다.
