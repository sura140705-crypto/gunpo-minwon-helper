## Ⅱ. 설치 방법

1. **키오스크 PC에 크롬(Google Chrome) 설치** (없을 경우 1회만).
2. `키오스크배포` 폴더를 키오스크 PC의 원하는 위치에 복사.
   - 예: `C:\민원도우미\`

## Ⅲ. 실행 방법

### 방법 A — 실행 파일(권장)
- `민원도우미_실행.bat` 를 더블클릭하면 **크롬이 전체화면(키오스크 모드)** 으로 첫 화면을 엽니다.
  - 자동으로 **시크릿(incognito) 모드**로 열려 방문 기록·다운로드 흔적이 남지 않습니다(개인정보 보호).
  - 주소창·뒤로가기가 감춰져 시민이 다른 사이트로 나가지 않습니다.
- **관리자가 종료할 때** : `Alt + F4` (전체화면 종료).

### 방법 B — 수동 실행
- 크롬에서 `index.html` 파일을 직접 열어도 됩니다(전체화면 잠금은 없음).

### 자동 시작(선택) — PC 켜면 자동 실행
1. `민원도우미_실행.bat` 우클릭 → [바로가기 만들기].
2. 만들어진 바로가기를 아래 폴더에 넣기:
   - `Win + R` → `shell:startup` 입력 → 열린 폴더에 바로가기 붙여넣기.
3. 다음 부팅부터 자동으로 도우미 화면이 뜹니다.

  - **용지 여백 : 없음**
  - **배율(크기) : 100% (실제 크기)** — ‘페이지에 맞춤’ 사용 금지
- 가능하면 크롬 인쇄 기본값을 위 설정으로 미리 맞춰 두면 시민이 매번 조정하지 않아도 됩니다.

## Ⅴ. PDF 저장 차단 설정 〔필수 · 설치 시 1회〕

키오스크는 **인쇄만 하고, 파일로는 저장할 수 없어야** 합니다.
설정하지 않으면 시민이 인쇄창에서 **‘PDF로 저장’을 골라 개인정보가 담긴 파일을 이 PC에 남길 수 있습니다.**

이 차단은 브라우저 화면(앱)에서는 막을 수 없어, **PC 설정을 한 번 바꿔 주어야** 합니다.
배포 폴더의 `관리자_개인정보보호_설정.bat` 이 아래 작업을 한 번에 처리합니다.

| 차단 경로 | 조치 내용 |
|------|------|
| 크롬 내장 ‘PDF로 저장’ | 크롬 정책 `PrinterTypeDenyList` 에 pdf·cloud 등록 → 인쇄창 목록에서 사라짐 |
| 윈도우 가상 프린터 | `Microsoft Print to PDF`, `Hancom PDF`, `OneNote`, `XPS`, 팩스 등 **파일로 저장하는 프린터 제거** |
| 재생성 방지 | 윈도우 기능(Print to PDF·XPS) 끄기 |
| 우회 경로 | 파일 저장 대화상자 차단, 다운로드 전면 차단 |

> **주의** — ‘Microsoft Print to PDF’ 만 지워서는 부족합니다. 시청 PC에는 한컴오피스가 설치된 경우가 많아 **`Hancom PDF` 프린터로도 PDF 저장이 됩니다.** 위 스크립트는 이런 프린터들을 함께 처리합니다.

### 실행 순서

1. **먼저 프린터 이름 확인** — `관리자_개인정보보호_설정.bat` 을 그냥 더블클릭(권한 불필요).
   - `/status` 없이 실행하면 관리자 권한을 요구하므로, 확인만 할 때는 아래처럼 실행합니다.
   - `Win + R` → `cmd` → 폴더로 이동 후 `관리자_개인정보보호_설정.bat /status`
   - 화면에 설치된 프린터 목록이 나옵니다. **키오스크에서 쓸 실물 프린터 이름**을 그대로 적어 둡니다.
2. **미리보기(선택)** — `관리자_개인정보보호_설정.bat /preview`
   - 무엇이 제거·설정될지 보여주며 **아무것도 바꾸지 않습니다.**
3. **적용** — `관리자_개인정보보호_설정.bat` 을 **마우스 오른쪽 → [관리자 권한으로 실행]**
   - 프린터를 1대만 쓰는 경우, 실물 프린터만 남기는 방식을 권장합니다:
     `관리자_개인정보보호_설정.bat /only "캐논 복합기"` ← 따옴표 안은 1번에서 확인한 이름
   - 지정한 프린터는 **기본 프린터로 함께 설정**됩니다.
4. **크롬을 완전히 종료한 뒤 다시 실행**(가능하면 PC 재시작).

### 적용 확인

- 일반 크롬 창에서 `chrome://policy` 접속 → `PrinterTypeDenyList` 값이 `pdf, cloud, privet, extension` 인지 확인.
- 도우미 화면에서 **[인쇄]** 를 눌러 인쇄창을 열고, 프린터 목록에 **‘PDF로 저장’이 없는지** 확인.

### 되돌리기

- `관리자_개인정보보호_설정.bat /undo` (관리자 권한) — 크롬 정책 삭제 + 윈도우 기능 복원.
- 단, `/only` 로 제거한 **다른 프린터는 자동 복원되지 않습니다.** [설정] → [프린터 및 스캐너] 에서 다시 추가하십시오.

> 참고 — 병행 대안으로 제공되는 Electron 설치본(`kiosk-app`)은 크롬 정책의 적용을 받지 않습니다. 위 **프린터 제거·윈도우 기능 끄기**는 공통으로 적용되지만, 정식 운영은 **크롬 실행 파일 방식(본 배포 세트)** 을 기준으로 하십시오.

## Ⅵ. 개인정보·보안

- 시민이 입력한 정보는 **PC 메모리에서만** 처리되고, 화면을 닫거나 새로고침하면 **즉시 사라집니다.** (저장·전송 없음)
- **3분간 아무 조작이 없으면** 경고 후 자동으로 첫 화면으로 돌아가 입력 내용이 사라집니다.
- **인쇄 창이 닫히면 즉시** 화면을 가리고, 출력물 수령 안내를 약 5초간 보여준 뒤 첫 화면으로 돌아갑니다(뒷사람이 앞사람 내용을 볼 수 없게). 인쇄를 취소한 경우에도 초기화되며, 인쇄 직전 안내 창에서 미리 알립니다.
- 실행 파일은 **시크릿 모드**로 열려 방문 기록·자동완성·다운로드 목록이 남지 않습니다.
- **인쇄만 가능하고 파일 저장은 차단**됩니다(제Ⅴ항 설정 필수).
- 출력물이 프린터에 방치되지 않도록, 시민이 **인쇄물을 직접 챙겨 가도록** 안내해 주십시오.
- 외부 서버와 통신하지 않으므로 내부망·폐쇄망 환경에서도 사용 가능합니다.

## Ⅷ. 문제 해결(FAQ)

| 증상 | 조치 |
|------|------|
| 실행 파일을 눌러도 안 열림 | 크롬 설치 여부 확인. 설치 경로가 다르면 `민원도우미_실행.bat` 파일 안의 `CHROME=` 경로를 수정. |
| 전체화면에서 나가고 싶음 | `Alt + F4` (관리자용). |
| 인쇄물 크기·위치가 이상함 | 프린터 설정에서 **여백 없음·배율 100%** 확인(제Ⅳ항). |
| 화면 카드가 안 보임 | 파일 12개가 **같은 폴더**에 함께 있는지 확인(index.html과 각 서식 파일). |
| 다른 사이트로 나가짐 | 방법 A(실행 파일=키오스크 모드)로 실행. |
| 인쇄창에 아직 ‘PDF로 저장’이 보임 | 크롬을 완전히 종료 후 재실행(또는 PC 재시작). 그래도 남으면 `관리자_개인정보보호_설정.bat /status` 로 설정 여부 확인(제Ⅴ항). |
| 인쇄할 프린터가 목록에 없음 | `/only` 로 실물 프린터 이름을 잘못 적었을 수 있습니다. [설정] → [프린터 및 스캐너] 에서 다시 추가. |
| 설정 파일 실행 시 “관리자 권한 필요” | 파일을 **마우스 오른쪽 → [관리자 권한으로 실행]**. 상태 확인만 할 때는 `/status` 사용. |
